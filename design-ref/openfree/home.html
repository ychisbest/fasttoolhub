Minilytics

Free 等级项目星标数: 0.3K

面向独立开发者的收入优先网站分析

数据分析与商业智能

Minilytics 是面向独立开发者和单人创始人的开源、收入优先网站分析工具。它展示访客来源、访客行为以及哪些来源带来了收入，并可自托管在 Cloudflare 免费计划上。

PromptHub

Free 等级项目星标数: 1.7K

本地优先的 AI 资产与智能体工作台

个人与桌面助手

PromptHub 是本地优先的桌面工作台，统一整理、版本管理、测试、同步、备份与分发提示词、技能、规则、MCP 条目、插件和智能体配置，并可将可复用资产一键应用到多种 AI 编程工具。

PilotDeck

Free 等级项目星标数: 4.9K

开源、面向任务的 AI Agent 工作台

智能体框架

PilotDeck 是开源的 AI Agent 工作台与面向任务的 AI Agent 生产力平台，围绕 WorkSpace 组织长程、多项目工作。它强调代码开源透明、模型自由选择、Agent 行为白盒可追溯，并以项目级隔离的文件、记忆与技能，配合白盒记忆、智能路由和常驻后台执行，把任务推进到可交付成果。

Spec Kit

Free 等级项目星标数: 142.9K

为编程代理提供结构化规范流程

智能体框架

Spec Kit 是开源工具包，为 AI 编程代理提供结构化流程和可复用模板，支持规范驱动开发、缺陷修复和想法评估，让意图与证据先于实现。

tuios

Free 等级项目星标数: 5.9K

面向编码代理的终端窗口管理器。

编程 Harness 与命令行运行时

tuios 是一个终端窗口管理器与多路复用器，提供平铺窗格、浮动窗口、九个工作区、保持会话存活的守护进程、跨主机访问会话，以及用于跟踪编码代理工作、审批、问题和失败的集中收件箱。

e2e

Free 等级项目星标数: 11.9K

面向 Web 与移动应用的 AI 辅助端到端测试

测试生成与质量保障

e2e 是可定制的 TypeScript 端到端测试框架，面向 Web 与移动应用，将 AI 代理操作与确定性定位器和断言结合。

brag

Free 等级项目星标数: 18.5K

一条命令把项目变成 20 秒发布短片

视频生成

brag 是一个代理技能，可用一条命令把刚完成的项目变成可分享的 20 秒发布短片，包含配乐、动效和分享文案。

Moli

Free 等级项目星标数: 20.6K

面向 AI 智能体的开源无头浏览器

智能体 SDK 与运行时

Moli 是用 Rust 构建的开源无头浏览器，面向 AI 智能体，可通过 CLI、CDP 和 WebDriver 获取与提取网页、搜索网页并自动化浏览器任务，采用结构优先设计，仅在需要时进行布局和绘制。

EdgeEver

Free 等级项目星标数: 2.6K

AI 原生、可自托管的笔记与知识库

知识库应用

EdgeEver 是一款开源 AI 原生笔记与知识库工作区，保留经典三栏布局，支持即时多设备同步、原生 MCP 与 ACP 智能体集成，并可作为 Evernote 或 Obsidian 的替代方案，在 Cloudflare 免费额度内运行或通过 Docker 自托管。

DATAGEN

Free 等级项目星标数: 1.8K

AI 驱动的多智能体研究助手

数据分析与商业智能

DATAGEN 是 AI 驱动的多智能体研究助手，可自动完成假设生成、数据分析与报告撰写。

CowAgent

Free 等级项目星标数: 47.6K

开源超级 AI 助手与 Agent Harness

智能体框架

开源超级 AI 助手与 Agent Harness，可规划并执行任务，调用工具与技能，借助长期记忆和个人知识库持续成长。支持多模型、多渠道和多智能体，轻量可扩展，提供一行安装，可在笔记本或服务器上长期运行。

WebLLM

Free 等级项目星标数: 19.3K

高性能浏览器内大语言模型推理引擎

边缘与端侧推理

WebLLM 是高性能浏览器内大语言模型推理引擎，借助 WebGPU 在浏览器中直接运行模型，无需服务器端处理。它兼容 OpenAI API，支持流式输出、JSON 模式、自定义模型和多种开源模型系列。

Folo

Free 等级项目星标数: 39.2K

AI RSS 阅读器，汇集文章、新闻与播客

知识库应用

Folo 是一款 AI RSS 阅读器，将文章、新闻和播客汇集到统一时间线中，并提供星标收藏与主题分类，帮助你整理和浏览关注的内容。

AI Website Cloner Template

Free 等级项目星标数: 37.3K

用一条命令让 AI 编码代理克隆任意网站

编程智能体

AI Website Cloner Template 让 AI 编码代理接收网址，并用一条命令将网站重建为干净的 Next.js 应用。它提供克隆技能、代理说明、资产组织与对比流程。相关的 Everything AI Discord 社区为成员提供语音和文字聊天。

OpenRig

Free 等级项目星标数: 8.2K

在你自己的机器上运行持久的编程智能体团队

编程智能体

OpenRig 是开源软件，可在你自己的机器上构建并运行由 Claude Code、Codex 和 Pi 组成的持久编程智能体团队，具备角色、共享上下文和归属明确的工作。

HumanLayer

Free 等级项目星标数: 12.3K

多人在线编码智能体 IDE 与云端

编程助手与编辑器

HumanLayer 是支持多人在线协作的编码智能体 IDE 与云端，可在本地工作站到远程运行环境之间运行并协同引导编码智能体，帮助其在复杂代码库中解决难题。

OmniRoute

Free 等级项目星标数: 80.6K

一个端点接入众多提供商，支持自动回退。

模型网关与路由

OmniRoute 是免费开源的 AI 网关，通过一个兼容 OpenAI 的端点路由数百家提供商，支持自动回退、19 种路由策略、上下文压缩、MCP 与 A2A 服务，以及本地优先的自托管部署。

Omnara

Free 等级项目星标数: 3.2K

开源托管式智能体平台

智能体构建器

Omnara 是一个开源托管式智能体平台，也可自托管，定位为 Claude Managed Agents 和 OpenAI Agents API 的替代方案。它可在任意模型和任意机器上运行 AI 智能体，并内置工具、密钥、权限与流式能力。

Cindy

Free 等级项目星标数: 3.7K

开源、开箱即用的 AI Agent，想到就能做到

编程智能体

Cindy 是开箱即用的开源 AI Agent，将多种 harness、模型与工具整合为一个智能体，在你的项目和应用中完成实际工作。第一天即可使用，并可随你的需要持续塑造。想到，就能做到。

Agent Toolkit for AWS

Free 等级项目星标数: 3K

AWS 官方支持的 MCP 服务器、技能与插件，助力 AI 编码代理

MCP 服务与工具连接器

AWS 官方支持的 MCP 服务器、技能和插件，帮助 AI 编码代理在 AWS 上构建、部署和管理应用。支持 Claude Code、Codex、Cursor、Devin、Kiro 和 fx。

3D Model Anything

Free 等级项目星标数: 1.3K

用 iPhone LiDAR 捕捉房间并重建可编辑 Three.js 场景

智能体技能与工具库

3D Model Anything 通过 iPhone LiDAR 与照片采集房间，借助 AI 编码智能体重建可编辑的 Three.js 场景，并支持在浏览器中查看结果。

ManimGX

Free 等级项目星标数: 2.1K

面向智能体的极速 3D 动画引擎

视频编辑与动画

ManimGX 是面向智能体的极速 3D 动画引擎，兼容 Manim CE 的 API。它结合 Manim 的 Python API 与 Rust GPU 核心，快速渲染数学和 3D 视频。

Rakazo

Free 等级项目星标数: 3K

运行持久 AI 队友的开源平台

智能体框架

Rakazo 是一个用于运行持久 AI 队友的开源平台，是 Grok Bot 的开源替代方案。你可以自选模型和沙箱，也可在本地运行完整技术栈。

Hindsight

Free 等级项目星标数: 53.2K

会学习的智能体记忆系统

智能体记忆

Hindsight 是面向 AI 智能体的长期记忆系统，通过类型化事实、整合观察、多策略召回与反思式推理，让智能体跨会话积累并运用记忆；Memlake 可在对象存储上以低于 100ms 的 p99 延迟服务 1 亿条记忆。

DSPy

Free 等级项目星标数: 38.8K

编程而非提示，构建 LLM 程序

应用框架

DSPy 是一个用于构建 AI 系统的 Python 框架。它把任务表达为结构化签名而非提示，并通过模块和优化器调优提示与权重，从而得到可维护、模块化且可优化的程序。

Vane

Free 等级项目星标数: 36.9K

隐私优先的 AI 问答引擎

搜索与答案引擎

Vane 是一款隐私优先的 AI 问答引擎，完全运行在你自己的硬件上。它结合互联网知识与本地 LLM（Ollama）及云服务提供商（OpenAI、Claude、Groq），在提供带引用来源的准确答案的同时，确保搜索完全私密。

MarkItDown

Free 等级项目星标数: 191.8K

将文档与媒体转换为 LLM 可用的 Markdown

文档解析与 OCR

MarkItDown 是轻量级 Python 工具，可将 PDF、Office 文档、图片、音频、HTML、文本类格式、ZIP、YouTube URL 和 EPub 转换为 Markdown，并尽量保留标题、列表、表格和链接等结构，面向 LLM 与文本分析流程。

Strata

Free 等级项目星标数: 31.2K

在自己的 PC 上运行 Qwen3.8-Flash-Next

聊天界面

Strata 让 125B 参数的 Qwen3.8-Flash-Next 在消费级 PC 上运行，提供 Windows/Linux 一键安装、本地推理引擎、localhost 上的 OpenAI/Anthropic 兼容 API，并可选图像输入。

PageIndex

Free 等级项目星标数: 35.9K

无向量、基于推理的长文档 RAG 引擎

RAG 框架

PageIndex 是一个无需向量库、基于推理的 RAG 引擎，为每份文档构建层级树索引，并由大模型在树上推理检索，无需向量数据库或文本分块，即可获得可追溯、上下文感知的答案，适用于长篇复杂文档。

CorridorKey 2.0

Free 等级项目星标数: 1.1K

一键完成绿幕与蓝幕抠像

视频编辑与动画

CorridorKey 2.0 是一款可在本地 VFX/剪辑软件中运行的一键绿幕与蓝幕抠像工具，提供 Resolve、Nuke、After Effects、Premiere 和 Blender 插件；一次购买即可获得全部插件，无需订阅，并附带独立应用。

DwarfStar

Free 等级项目星标数: 24K

面向消费级硬件的精选大模型本地推理引擎

推理服务与 API

DwarfStar 是一个小型原生推理引擎，专注于在消费级硬件上运行 DeepSeek、GLM 和 Qwen 等精选大语言模型，支持 Metal、CUDA 和 ROCm。它要求使用项目自身产出的 GGUF 文件，并非通用 GGUF 运行器。

Laya

Free 等级项目星标数: 34K

单次前向完成类型化决策并给出校准概率

语言模型

Laya 是面向类型化选择、评分和是/否问题的非自回归 System 1 决策引擎。它对文本等进行单次前向推理，返回经过校准的概率，覆盖 100 多种语言，并由 Router 将请求路由到合适的检查点。

New API

Free 等级项目星标数: 50.6K

面向模型、应用与智能体的统一 AI 网关

模型网关与路由

New API 是一个自托管的 AI 网关和模型枢纽，通过兼容 OpenAI、Claude 与 Gemini 的接口统一接入 30+ 家 AI 服务商，并在一个控制台中管理路由、访问、用量和成本。

Onyx

Free 等级项目星标数: 32.3K

为您的员工和AI代理提供完整上下文

智能体框架

Onyx 是一个开源 AI 平台，连接企业知识库，为人类和 AI 代理提供准确、快速且节省 token 的上下文。支持自托管部署、50+ 连接器，并兼容所有主流 LLM。

Concat

Free 等级项目星标数: 10.9K

免费开源的 CapCut 替代方案

视频编辑与动画

Concat 是一款免费、开源、本地优先的视频编辑器，也是 CapCut 的替代方案。它提供自动字幕、文本转语音、声音克隆、背景移除、关键帧、特效、标题、多轨剪辑和 4K 导出，且不添加水印。
