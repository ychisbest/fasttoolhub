intro: "**Solana Confidential Compute** is the open-source confidential-computing toolkit the Solana Foundation and the Nito team formally launched on 13 November 2026. The official post [Solana Confidential Compute: Private AI, Verified Onchain](https://solana.ai/blog/nito-solana-confidential-compute) is labeled “Solana Foundation / Launch / 13 November 2026.” It describes an open-source SDK and on-chain verification program built by the Nito team in coordination with the Foundation, used to verify hardware attestations and publish a public record on Solana that applications, agents, and users can inspect. The AI computation happens off-chain; Solana holds the verification record, and publishing that record does not require publishing the conversation or the private inputs.\n\nThe official flow is: a machine inside a confidential VM generates a signing key that exists only inside that hardware; the hardware signs a report binding the key to a recent Solana slot; the on-chain program verifies the report and records the key, hardware type, and an expiry date; the machine then signs the answers it produces with that key, and anyone receiving an answer can check the signature and look up the key’s record on Solana. The product page at [solana.ai/confidential-compute](https://solana.ai/confidential-compute) lists what is in the kit: a verifier program live on Solana devnet, Rust and TypeScript SDKs, helpers for other programs to consult the verifier’s record, a daemon that runs inside an enclave, plus a command-line tool and a Docker image. Supported hardware includes AWS Nitro Enclaves, AMD SEV-SNP, and Google Confidential Space. The blog also says the current SDK covers Intel TDX and AMD SEV-SNP attestations, with NVIDIA GPU attestation still in progress. Official pages stress that the toolkit is in beta on Solana devnet, the security audit is not finished, it is for development use only, and mainnet follows the audit.\n\nThe same stack is also used to demonstrate **Confidential Chat** (open-weight models run in confidential hardware through Tinfoil’s confidential router; the browser verifies the attestation, then encrypts the prompt to a key only the verified enclave holds; Nito’s gateway relays ciphertext without the keys to read it) and **Milo**, an autonomous trading agent. The product page says the in-page chat demo is simulated, and the live chat is at [solana.ai/chat](https://solana.ai/chat).
