intro: "**Databox CLI** is the official **command-line interface** for the [Databox](https://databox.com/) analytics platform. It maps the public V2 API 1:1 into the terminal so you — or an agent — can manage data sources, datasets, ingestion, custom metrics, databoards, users, the organization and billing without opening the browser.\n\n@databoxHQ said it went live on Product Hunt on 2026-11-09, highlighting:\n\n- piping arbitrary JSON into Databox (for example `curl … | databox dataset ingest …`);\n- turning rows into metrics and tracing where the data came from;\n- about **10 agent skills** for Claude Code, Cursor and Codex;\n- safer automation: idempotency keys, `--json` output, clear exit codes, nightly-style retries, and a `--force` flag on destructive actions.\n\nInstall with `npm install -g databox-cli`, then `databox auth login`. Add every bundled skill with `npx skills add databox/databox-cli --skill '*'`. Source: https://github.com/databox/databox-cli . Docs: https://help.databox.com/manage-databox-using-the-cli . MIT licensed; Databox says it is available on every Databox plan."
explain: "## Why it matters\n\nHanding a BI product to an agent is painful if the model has to click around a web UI. Databox CLI turns 90+ commands into a scriptable mirror of the API and splits skills by area (auth, datasets, metrics, users, and so on) so an agent only loads what it needs. `--json`, exit codes, idempotency keys and `--force` are there because scripts and agents retry, and they write to real accounts. This is not another chat-with-your-dashboard bot — it is the existing agentic analytics platform, exposed in a terminal.\n\n## Limits\n\nIt helps teams that already use (or will use) Databox; it does not replace an arbitrary warehouse. Skill and command counts differ slightly across the GitHub README, the npm page and the Product Hunt copy (some say five core skills, some say ten area skills, some say 91 commands) — trust the version you install. Restrict the API key's scope before you let an agent create metrics or change users."
