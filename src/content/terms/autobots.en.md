intro: "**AutoBots** is the product Vorflux introduced in version 2.0: you hire an agent for a standing role (on-call, cloud cost, bug hunting, release manager and so on), it lives in its own Slack channel, and it works around the clock instead of finishing a single task. Vorflux founder Prasanna Sankar (a Rippling co-founder) introduced AutoBots in a [launch post](https://x.com/myprasanna/status/2120205408371634624) at 2026-11-10T17:22:15Z. The official account [@vorfluxai](https://x.com/vorfluxai/status/2120207179034906827) posted “Vorflux 2.0 is now live.” Docs are at [vorflux.com/docs/autobots](https://vorflux.com/docs/autobots), the directory is at [vorflux.com/bots](https://vorflux.com/bots), and the site is [vorflux.com](https://vorflux.com/).\n\nIn the launch post and the docs, Vorflux 1.0 already let people assign work from Slack or Linear to cloud coding agents and review it there, but someone still had to start the work, keep track, and ping the right person for approval. AutoBots are framed like a new hire ramping up: they connect to data sources, start with the highest-impact work, do more as their work is accepted, back off when nobody engages, and stay inside a budget. The docs say the product is called Autobots / AutoBots across the app (sidebar, hire page and edit page); a few older messages still say Worker bot and mean the same thing. Fourteen templates shipped at launch, each with a persona, a role definition, recommended integrations and default budgets (the docs say each template starts at $100 a day and $1,000 a week, changeable in the setup chat or under cost management). Examples include On-call Assistant, Cloud Cost Assistant, Code Janitor, Bug Bot and Release Manager.\n\nIn the same post Sankar said teams can bring existing Codex or Claude Code subscriptions, and that Vorflux had closed a $15 million seed backed by Y Combinator, Peak XV Partners, Alliance DAO and a list of individual investors. Those funding and “practically free” remarks are the founder’s statements; terms and pricing are whatever the site and the contract say.
