intro: "**NEAR AI RED** is a cybersecurity program from **NEAR AI** (the AI arm of the NEAR ecosystem), launched on **October 29, 2026** together with **private, uncensored (\"abliterated\") models** for security research. The models — abliterated versions of **DeepSeek V4.1 Flash** and **Qwen3.8 27B** — have their refusal behaviour reduced so they answer vulnerability questions instead of refusing, and they run inside **trusted execution environments (TEEs)** on NEAR AI Cloud so that, NEAR says, not even NEAR AI can see the prompts.\n\nThe models are open to every NEAR AI Cloud account; **NEAR AI RED** is the optional membership for red teams, auditors and AppSec teams, offering discounts, early access, workshops and support. On October 30–31 NEAR also released the open-source **NEAR AI RED Sandbox**, a disposable microVM for running security agents safely on Apple-silicon Macs."
explain: "## What's included\n\n**Models (open to all NEAR AI Cloud accounts)**\n\n| Model | Context | Price per 1M tokens (in / out) |\n|---|---|---|\n| DeepSeek V4.1 Flash (abliterated) | ~1.05M | $0.30 / $1.20 |\n| Qwen3.8 27B (abliterated) | 262K | $0.04 / $1.35 |\n\n- **Confidential inference** in TEEs, with optional end-to-end encryption.\n- **Verifiable protections** — hardware attestation and, where supported, signed responses.\n- **OpenAI-compatible API** — switching is a base-URL change.\n\n**NEAR AI RED membership (optional, by application)**\n\n- 20% off the first month of inference\n- Early access to new models and security features\n- Private Slack channel and dedicated support\n- Workshops, co-marketing and input into the roadmap\n\nMembers commit to use the models only for **lawful security research or authorized testing** on systems they own or have written permission to test.\n\n**RED Sandbox (open source)** — each session gets a fresh microVM; the agent's commands and file edits run only inside it, files are copied in, network is blocked unless specific sites are allowed, the API key stays outside, and only files saved to the output folder come out. Early version supports Apple-silicon Macs only.\n\n## Why it matters\n\nMainstream models often refuse to help with exploit reproduction because they cannot tell defenders from attackers. NEAR's pitch is to give defenders the same uncensored capability attackers already use, but privately and verifiably."
