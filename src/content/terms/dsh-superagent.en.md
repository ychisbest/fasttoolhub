intro: "**dsh-superagent** is an open-source **proactive coding agent** released by **DeepSeek** on **October 31, 2026** as the repository `deepseek-ai/dsh-superagent-prototype`. It is packaged as a bundle for **DeepSeek Harness** (the \"DSH\" in its name), DeepSeek's agent runtime, and it accompanies the team's article *Exploring Super-agent Design: Towards a More Autonomous Agent System*.\n\nInstead of waiting in a chat window, dsh-superagent \"lives\" on **one GitHub repository**. It listens to GitHub events and, optionally, **Feishu (Lark)** chats. When an allowed person asks it for work, it opens a **work item**, does the job in its own agent session and directory, and replies in the original conversation — typically with a **pull request**. A small web panel shows what needs a human.\n\nDeepSeek is explicit that this is **research code, not an official product**: much of it was written by coding agents, it differs from their internal version, and some designs in the article are not implemented. It is MIT-licensed and passed 1,300 GitHub stars within hours of release."
explain: "## How it works\n\n- **Always-on, one repo**: the agent is bound to a single GitHub repository and reacts to issues, PR comments and (optionally) Feishu messages.\n- **Authorization first**: it acts only when an **allowed person** asks, or when a **rule the team wrote** permits it. Proactive rules can start in a mode that only records what the agent *would* have done, before being trusted to act.\n- **Work items and isolation**: every request becomes a work item with its own agent session and working directory, so parallel tasks do not trample each other.\n- **Answer where you asked**: results go back to the original thread — a PR, a reply, or a question for a human.\n- **Panel**: a web panel lists items that are blocked on people.\n\n## Design philosophy\n\nThe core idea is \"**take as little human attention as possible, and give as much value as possible**\". DeepSeek argues single-task agents are already strong; the bottleneck is human attention. An agent that can act for a whole team can also waste a whole team's attention, so it speaks only when someone must act or can use the result.\n\n## Documentation\n\nThe repo ships numbered docs: 000 Philosophy, 001 Domain model, 002 Authorization, 003 Execution, 004 Prompts, 005 Panel, 006 Deployment, 007 Architecture and 008 Cookbook (adding a Source). `pnpm check` runs typecheck, tests and build.\n\n## Caveats\n\n- Research prototype; review the code before running it.\n- Requires DeepSeek Harness.\n- Not identical to DeepSeek's internal system."
