intro: "**Audited ZDR** (Audited Zero Data Retention) is a provider tier **Vercel** added to **AI Gateway** on 23 November 2026. The official account [@vercel](https://x.com/vercel/status/2124859223783727106) introduced it at 13:34 UTC, with the blog post: [vercel.com/blog/introducing-audited-zdr-on-ai-gateway](https://vercel.com/blog/introducing-audited-zdr-on-ai-gateway).\n\nVercel’s argument is that companies already send source code, customer records, and regulated data through inference providers, while “we do not retain your data” is still mostly a contract and a self-attestation. A provider is labeled Audited ZDR only after an independent security firm tests those claims against its code, infrastructure, and live traffic, then publishes the report. Launch partners are **Baseten**, **Modal**, and **Wafer**, with reports expected by **8 December 2026**.\n"
explain: "## What the audit covers\n\nTo enter the tier, a provider must hire an independent firm to audit the serving path for every model, endpoint, feature, and tool that handles AI Gateway traffic. The audit is meant to confirm that customer data—prompts, completions, system prompts, embeddings, files, images and audio, tool-call payloads, and any derived data that could identify the customer—is never written or retained on durable storage. Coverage includes logs, traces, metrics, crash dumps, prompt caches, abuse monitoring, analytics, backups, support tools, and training, fine-tuning, and evaluation datasets.\n\nAfter a response is returned to AI Gateway, that content should be deleted from the provider’s systems. If a request uses a cache such as a KV cache, it must stay in volatile storage only for the request and be disclosed. The audit also requires that a request marked ZDR never fails over to a non-ZDR endpoint; that no human or automated process accesses customer data except to handle the request; that sub-processors follow the same rules; and that customer data is not used for training. Auditors review serving-path source code and infrastructure configuration, then send marked prompts through AI Gateway and search the provider’s logging, caching, and storage for traces. Passing providers publish the report under the auditor’s name.\n\n## How it relates to existing ZDR\n\nA Vercel engineer noted that AI Gateway has **already offered zero data retention for months**. Audited ZDR is a new independently verified tier on top of that, plus canary monitoring between audits: prompts contain unique, unindexed URLs, and any request to those URLs triggers an investigation. The blog also ties the launch to the earlier team-wide ZDR routing control and to Vercel’s **ISO/IEC 42001:2023** certification. So this is not the first appearance of ZDR on the Gateway; it is a public verification layer, with a team-wide toggle that, when enabled, routes and fails over only across providers with published audits that meet the bar.\n"
