intro: "**Gemini Decision 1** is the new model Google announced on November 11, 2026, and **Gemini Decisions API** is the endpoint that serves it. The official post is [Gemini Decisions API: Fast, calibrated multimodal decisions](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/), by Min Choi, Product Manager, Google DeepMind, and Felix Yu, Principal Scientist, Google DeepMind. The blog says the company is introducing the Gemini Decisions API, a new endpoint for fast, closed-set decisions powered by the new Gemini Decision 1 model (`gemini-decision-1`), available through the Gemini API in Google AI Studio.\n\nOfficially, the Decisions API gives purpose-built primitives for bounded choices such as tool selection, policy checks, model routing, and context grading. You can pass one multimodal input across text, images, audio, video, and PDFs (up to 256K tokens) along with up to 1,000 independent questions. Rather than generating answer text token by token, Gemini Decision 1 scores candidate options in a single forward pass and returns probabilities and confidence scores. The blog gives end-to-end latency of 150–250 ms, and pricing of $0.10 per 1M input tokens with zero output tokens billed. It also says that, across a shared benchmark suite, Gemini Decision 1 with the Decisions API is nearly 5x cheaper than Gemini 3.5 Flash-Lite with the Interactions API, and that median model-compute latency is 50–100 ms (150–250 ms end-to-end) and remains nearly flat from 1 to 100 questions per request at contexts up to 16K tokens. Those latency, price-comparison and “leads the suite / lowest calibration error” figures are the company’s; this page does not independently reproduce them.\n\nThe official API has three question types: `noul` (yes/no, with optional true/false criteria), `choice` (2 to 255 options, returning the winner and normalized probabilities), and `score` (an ordered rubric, returning a continuous weighted score and per-level probabilities). Every answer includes a confidence score from 0 to 1 so code can send ambiguous cases to a fallback or a human reviewer. The `input` field uses the same `Content` block format as the Interactions API. Google says its own teams are already using it: Gemini Notebook as a real-time router for model tier and thinking level (up to 40% lower latency on everyday queries, with deeper models reserved for complex tasks); the rapid canvas experiment in Stitch, to generate playable product-flow wireframes in seconds; CC from Google Labs, to pick an emoji from a palette of more than 200 options; and Google Search, as a safety layer for MCP tools against adversarial evals within the latency envelope.\n\nThe blog says you can start today with an API key in Google AI Studio, including an API no-cost tier for prototyping, plus Doorstep Parcels, Speed Sketch, and Find the Zoo Keeper demos and Python, JavaScript, and REST guides. Ecosystem integrations are rolling out across OpenRouter, LangChain, Vercel, LiteLLM, Pydantic AI, Pipecat, LiveKit, and OpenCode alongside the `google-genai` SDKs, with support coming soon to Gemini in Google Cloud. OpenRouter already lists [google/gemini-decision-1](https://openrouter.ai/google/gemini-decision-1).
