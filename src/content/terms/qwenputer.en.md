explain: "## Key points\n\n1. **Gated DeltaNet as RAM**: Qwen3.5's DeltaNet layers carry a running state that the delta rule can overwrite one row at a time, exactly, so each row works as a memory cell. The CPU keeps its code, data, registers and program counter there.\n2. **Capabilities**: runs C and MicroPython programs inside the model's forward passes and passes the official riscv-tests suites; the ISA is RV32IM + Zba plus a bignum coprocessor.\n3. **How it's used in chat**: it piggybacks on Qwen3.5's tool-call format. Qwen writes a `<tool_call>` for `calc`, but nothing outside the model runs it; the computer layers read the call, execute it on the internal CPU, and the model itself writes the `<tool_response>` digit by digit.\n4. **Benchmarks** (greedy, 40 problems per set): synthetic integer arithmetic 75.0 → **97.5**; DeepMind `mul_big` 55.0 → **97.5**; `div_big` 72.5 → **97.5**; `mul_div_multiple_longer` 90.0 → **100**, on par with base Qwen calling a real Python tool. About 230,000 replayed output positions showed **zero mismatches** against a reference machine, and text behaviour matches the base model (KL 6e-4).\n5. **Costs**: 18.8 GB in bf16 (mostly zero padding; the computer has about 1M nonzero weights); the Triton executor runs about 3,200 trace tokens per second on an L4, slower than native hardware.\n\n## Why it's tracked\n\nA distinctive name and a novel idea (\"a computer compiled into LLM weights\") that became an X trending story in this scan window. The weights were created on Oct 19, but the radar had not tracked it before."
