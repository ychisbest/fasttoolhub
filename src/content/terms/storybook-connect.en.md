intro: "**Storybook Connect** is a **JetBrains IDE plugin** built by **Callstack** together with **JetBrains (the WebStorm team)** and **Storybook**. On **November 2, 2026** it was announced as available **across JetBrains IDEs** — WebStorm, IntelliJ IDEA, PhpStorm and others (WebStorm 2026.1+ required).\n\nIt makes Storybook a first-class part of the IDE: a dedicated tool window to browse every story, one-click jumps from a story to its component, starting/stopping the Storybook server from the IDE, and **two-way selection sync** with the browser preview. Crucially it ships **agent-ready Storybook skills and a CLI** that find components missing stories and generate new ones from their TypeScript props."
explain: "## Key features\n\n| Feature | Details |\n|---|---|\n| Story tree | Searchable list of every story; click through to the component source |\n| Server controls | Start/stop Storybook inside the IDE and view console logs |\n| Two-way sync | Selecting a story in the Storybook browser makes the IDE follow it |\n| Setup & upgrades | Guides installation when Storybook is missing and upgrades when outdated |\n| AI skills | `author-storybook-jetbrains` (official story-writing guidance) and `discover-storybook-jetbrains` (drives the CLI to audit coverage and generate missing stories) |\n| BYOK | Bring your own key for compatible AI providers |\n\n## Design approach\n\n- **Deterministic steps vs. AI judgment** — a CLI handles repeatable work (finding components without stories, scaffolding files); the AI assistant only steps in where component context matters, and writes only after the developer approves.\n- Generated stories follow **Component Story Format (CSF)**, covering variants, naming/structure, mocking and interaction tests.\n- Works with **React, Vue and Angular** on macOS, Windows, WSL and Linux.\n- Integrates with **JetBrains Air**, the IDE's built-in agentic development layer.\n\n## Background\n\nWebStorm's previous Storybook support was buried inside the React Buddy plugin. Callstack built the MVP in 25 working days with AI-assisted development; a WebStorm engineer then integrated it, and it ships as a new plugin alongside WebStorm 2026.3."
usage: "## Getting started\n\n1. **Install** — use WebStorm 2026.1+ (or another JetBrains IDE), then Settings → Plugins → Marketplace → search **Storybook Connect**.\n2. **Set up** — open a front-end project (React / Vue / Angular / Next.js…), go to View → Tool Windows → Storybook Connect and click **Set Up Storybook**.\n3. **Enable AI** — make sure the bundled **JetBrains Air** plugin is enabled; Storybook Connect installs its two Storybook skills into the project.\n4. **Fill coverage gaps** — ask the AI assistant to analyze missing stories, approve the plan, and it generates CSF stories plus interaction tests; or drive the Storybook Connect CLI from the built-in terminal.\n5. **Day to day** — browse and search stories in the tool window with two-way sync to the browser preview.\n\n> Docs: jetbrains.com/help/webstorm/storybook-connect.html; background: Callstack's case study."
