intro: "**OpenRouter MCP** is a **remote Model Context Protocol (MCP) server** hosted by **OpenRouter** at https://mcp.openrouter.ai/mcp . Product page: https://openrouter.ai/mcp ; docs: https://openrouter.ai/docs/guides/overview/mcp-server .\n\nIt plugs OpenRouter into agents and coding tools you already use—**Claude Code**, **Codex CLI**, **OpenCode**, **Cursor**, or any MCP client—so the assistant can pull **live** OpenRouter data and run selected generation tools without installing a local server.\n\nHighlights:\n\n- **Live catalog & account data**: models, prices, endpoints, rankings, docs search, remaining credits;\n- **Billable inference tools** (charged to the connected OpenRouter account): e.g. test messages and image generation; the product surface also covers speech/video generation workflows described on the MCP page;\n- **Auth**: browser OAuth (dedicated MCP key, typically **7-day** expiry with a default **$10** spend cap) or `Authorization: Bearer <OPENROUTER_API_KEY>` for clients without OAuth;\n- Transport: **Streamable HTTP** remote MCP—nothing installed locally."
explain: "## Problem\n\nCoding agents often guess model names, prices, and capability from stale training data. Teams also leave the editor to open dashboards just to check credits or try a prompt. OpenRouter MCP keeps that loop inside the agent.\n\n## How it works\n\n1. Add the remote URL `https://mcp.openrouter.ai/mcp` in your MCP client;\n2. Complete OAuth (or pass an API key as Bearer). OpenRouter mints a dedicated key labeled for MCP use;\n3. Tools proxy the public OpenRouter API with that key—**live data, no local state**. Source code is not sent unless you call generation/feedback tools.\n\nDocumented tools include `list-models`, `get-model`, `list-model-endpoints`, `get-credits`, `list-daily-model-rankings`, `list-benchmarks`, `search-docs`, `send-message`, `generate-image`, and others (see the docs tool table).\n\n## Limits\n\n- MCP is for **building/choosing models inside the agent**; production app inference still goes through the normal OpenRouter API;\n- MCP keys expire (commonly within 7 days) and may need re-auth;\n- Generation tools are billable—watch the spend cap."
usage: "## Who it's for\n\n- Developers using Claude Code, Codex, OpenCode, Cursor, or other MCP clients who route models via OpenRouter;\n- Teams that want in-editor model discovery, credit checks, and quick prompt tests against live OpenRouter data.\n\n## Getting started\n\n1. Read https://openrouter.ai/mcp and https://openrouter.ai/docs/guides/overview/mcp-server ;\n2. Add the server, e.g. Claude Code: `claude mcp add --transport http openrouter https://mcp.openrouter.ai/mcp` then `claude mcp login openrouter`;\n3. Cursor: put `{ \"mcpServers\": { \"openrouter\": { \"url\": \"https://mcp.openrouter.ai/mcp\" } } }` in `~/.cursor/mcp.json` and authenticate;\n4. Prefer `list-models` / rankings / benchmarks before hard-coding a model; treat generation tool calls as paid API usage."
