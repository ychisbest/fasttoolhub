intro: "**Aura Autopilot** is an **open-source autonomous game tester** launched by **Ramen** — the startup behind the **Aura** AI agent for Unity and Unreal developers — on **October 30, 2026**. Autopilot plays your game **in real time**, using real user input events, looks for bugs, and **gets better the more it plays** through per-game continual learning.\n\nIt works in **Unreal Engine 5, Unity 6 and Godot 4** on Windows and macOS, can be steered with plain-English prompts, and runs either through an Aura subscription, your own API keys, or your existing **Claude Code / Codex** subscription via skills and an MCP server."
explain: "## Key points\n\n1. **Architecture**: an engine plugin (reads game state, injects real inputs), a Python agent service (hosts a coding agent, sandbox and per-game memory), a **coding agent** (Claude Code, Codex or OpenCode SDKs) that researches the game and writes a bespoke harness, and a real-time **decision model** (Jev via the TypeSafe SDK) that actually plays.\n2. **Prompt types**: Exploration (\"explore the crafting system\"), Testing (\"tell me everything that looks wrong\"), Verification (\"verify the tree shakes when hit\"), and Goal (\"kill the boss keeping health above 20%\").\n3. **Genres**: demonstrated on shooters, souls-likes, action RPGs, mobile match-3, survival crafting, turn-based JRPGs and RTS.\n4. **Claims**: ~3x faster than Aura's previous Verification Agent, higher accuracy than general coding agents (e.g. 7/7 vs Claude Code 5/7 in Ramen's comparison), and recursive self-improvement across runs.\n5. **Loop with Aura**: Aura builds a feature end to end, then Autopilot playtests it — build and test in one loop.\n\n## Why it matters\n\nAI makes building games faster, but QA and playtesting remain manual and slow. An open, engine-agnostic playtesting agent is a concrete step toward automated game QA."
usage: "## How to use it\n\n1. Download the prebuilt plugin from [tryaura.dev/autopilot](https://www.tryaura.dev/autopilot/) or build it from the GitHub release.\n2. Autopilot launches a play-in-editor window, reads the project source, plays, and generates a bug report when done.\n5.
