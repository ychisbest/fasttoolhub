intro: "**A2UI 1.0** 是 Google 于 2026 年 11 月 11 日在 Google Developers Blog 文章 [A2UI 1.0: Build delightful, fast, reliable, agentic experiences](https://developers.googleblog.com/en/a2ui-10-build-delightful-fast-reliable-agentic-experiences/) 中宣布的生成式 UI 开放协议的第一个稳定版本，作者为 A2UI 产品经理 Vishal Motwani 与 Google A2UI 团队。博客写到：“Today, we're releasing A2UI 1.0, the first stable version of our open protocol for generative UI.” 它让智能体用交互界面（例如确认表单或图表）作答，而不是只返回大段文字。开发者现在可以使用面向 Web、Android 和 iOS 的开源渲染器 SDK，以及面向 Python、TypeScript 和 Dart 的智能体 SDK。官方写到 Atlassian、Alation、Bloomberg 和 ByteDance 等公司已在使用。站点为 [a2ui.org](https://a2ui.org)，代码在 [github.com/a2ui-project/a2ui](https://github.com/a2ui-project/a2ui)。\n\n官方对协议的定位是：智能体描述要展示什么，每个应用用自己的原生组件来绘制；应用接收 A2UI 消息，并以自己的速度和安全性完成渲染。用户无论是在公司自己的应用里，还是在托管 MCP Apps 的第三方 AI 助手（官方举例为 Gemini 或 Claude）里碰到该公司的智能体，都能得到同样的低时延、信任边界和原生保真度。\n\n1.0 的新增内容，官方列出三条。稳定协议：加入双向函数调用，使机票或订座选择器可以当场查询可用性，并增加无障碍支持以及用于额外元数据的扩展。主流平台渲染库：Web 端可用 React、Angular 和 Lit；Flutter 可用于移动、Web 和桌面；iOS 为 SwiftUI；Android 的 Jetpack Compose 目前为 v0.9.1，v1.0 即将到来。Web 与 Flutter 渲染器也可在 MCP Apps 内工作，因此 A2UI 界面可以出现在支持 MCP Apps 的 AI 助手中。面向智能体的 SDK：在原有 Python 之外新增 TypeScript 和 Dart SDK，用于生成 skill、翻译消息和纠正错误；可切换的推理格式用于降低时延；Python 中的 A2UI Macros 提供程序化的组件展开与数据绑定。\n\n采用方方面，官方写到：Atlassian 把 A2UI 带进 Jira，智能体在工作项里用交互卡片向团队追问缺失细节或决策；Alation 的 Alation Intelligence Operating System（AIOS）用 A2UI 构建指标卡片与图表等信息流，同一信息流可以在 Claude 对话和 Alation 产品里以接近一致的布局呈现；ByteDance 于 2026 年 6 月发布了面向其跨平台框架 Lynx 的 A2UI 渲染器，Lynx 目前支持 A2UI 0.9，并在与 A2UI 团队一起适配 1.0。Google 内部方面，Gemini Notebook 用 A2UI 卡片询问幻灯片类型与主题并在生成前供人修改；组织可以注册以 A2UI 作答的智能体，Gemini 目前支持 A2UI 0.9.1。博客还写到，Gemini Enterprise 中的智能体已经可以使用 A2UI，团队正在把 Gemini Enterprise 升级到 A2UI 1.0。Google Cloud Tech 官方账号 [@GoogleCloudTech](https://x.com/GoogleCloudTech/status/2120563165557571629) 于 2026-11-11T17:03:51Z 发帖称：“Today we are releasing A2UI 1.0, now faster, easier, and stable, an open protocol and framework for generative UI across web, Android, iOS, wearables, TVs, and any other surface.”\n\n要点：\n\n- 官方博客：https://developers.googleblog.com/en/a2ui-10-build-delightful-fast-reliable-agentic-experiences/ ；站点：https://a2ui.org ；代码：https://github.com/a2ui-project/a2ui ；\n- 宣布帖：https://x.com/GoogleCloudTech/status/2120563165557571629 （2026-11-11T17:03:51Z）；\n- 这是 **Google 的一个具体协议版本名**，是 A2UI 的第一个稳定版，不要把它写成仍在 0.9 / 0.9.1 预览阶段，或与 MCP Apps 本身混为一谈。"
