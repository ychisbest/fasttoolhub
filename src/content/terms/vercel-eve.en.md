intro: "**eve 1.0** (also referred to as **Vercel eve**) is the open-source agent framework [Vercel declared generally available on 17 November 2026](https://vercel.com/blog/eve-is-now-generally-available). The official blog opens with “Today we're announcing eve 1.0, the open-source framework for building production-ready agents,” and notes more than 230 releases since a June public preview. The product site is [eve.dev](https://eve.dev); the code lives at [github.com/vercel/eve](https://github.com/vercel/eve).\n\nThe pitch is a production harness you own: it calls models, runs tools, and delegates work to sub-agents. An open-source Workflow SDK persists progress so a run can resume after a crash. For managed hosting, you can deploy an eve agent to Vercel, where Vercel Workflows handles durable execution and Vercel Sandbox isolates agent-generated code.\n\nThe name is not Anthropic’s already-filed **Project EVE**, a research project in which Claude agents play EVE Online / EVE Frontier. Vercel eve is an engineering framework. This entry records the 1.0 GA name, not a new foundation model."
explain: "Vercel describes eve’s core as a harness you control: a loop that calls models, executes tools, and hands work to sub-agents. You can swap models, add or replace tools, edit instructions, and decide which actions need human approval and what data is collected. The open-source Workflow SDK saves progress as the agent runs, so a crash does not mean starting over. Multiplayer sessions and agent-to-agent calls are described as built-in.\n\nThe blog’s example uses include software factories that turn requests into tested pull requests, “company brains” that answer questions from business data, and customer-facing agents in a product. Publicly cited adopters include Rillet, which reported roughly tripling its shipping rate in three months, and Clay, which built a Slack data agent called monty. A Lindy framework roundup has called eve a strong fit for durable backend agents.\n\nThe path from the June preview to the 17 November 1.0 GA is described as faster performance, broader integrations, better observability, and tighter security controls. License and install details follow the GitHub repo and eve.dev docs at the time you use them (the repo is Apache-2.0). eve is a framework for building and running agents, not a newly released base model."
usage: "Start with [Introducing eve 1.0](https://vercel.com/blog/eve-is-now-generally-available), then use [eve.dev](https://eve.dev) and [github.com/vercel/eve](https://github.com/vercel/eve) for install, APIs, and hosting. The intended path is to assemble a harness in your own code (model, tools, approval rules), persist runs with the Workflow SDK, and, if you want managed hosting, deploy to Vercel Workflows while running untrusted code in Sandbox.\n\nWhen evaluating it, ask whether you actually own and can change the harness, whether persistence covers the failure modes you care about, and which tool calls must be approved by a person. If you only need a chat model or a differently named research project, that is not eve.\n\nIf a search result says “Project EVE,” check whether the source is Vercel or Anthropic before following a doc or repo link."
