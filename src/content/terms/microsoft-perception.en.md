intro: "**Microsoft Perception** is the security product name Microsoft declared generally available at Ignite on 17 November 2026. The Tech Community post [What's new with Microsoft Perception at Ignite 2026](https://techcommunity.microsoft.com/blog/perception-blog/whats-new-with-microsoft-perception-at-ignite-2026/4571834) is explicit: the idea introduced as **Project Perception** in July becomes Microsoft Perception at Ignite and goes GA. The same-day Security blog, [Security for the agentic era, powered by Microsoft Perception](https://www.microsoft.com/en-us/security/blog/2026/11/17/security-for-the-agentic-era-powered-by-microsoft-perception/), frames it as a new cyber stack for a world where attackers also use AI and the time from disclosure to exploit is shrinking from months to minutes.\n\nMicrosoft says this is not a chatbot bolted onto old tools. It is a stack that connects signals, intelligence, and orchestration: specialized models and agent teams share work across investigation, protection, and remediation, while security staff set priorities and approve critical actions. Red agents find and validate paths to compromise, blue agents triage alerts, investigate attacks, and turn threat intelligence into detections, and green agents identify the exposures that matter most and coordinate remediation.\n\nThis entry records the GA product name Microsoft Perception. It is not the same name as everyday Microsoft 365 security alerting, or as Copilot UI changes announced at the same event."
explain: "Perception is presented as defense built for an agentic era. Attackers can find and exploit weaknesses in parallel and often automatically; defense that still works “one alert, one investigation, one response” falls behind. Perception’s orchestration harness assigns work to red, blue, and green agents, and playbooks organize those agents around a specific security outcome. Teams can also describe what they need in chat and follow the work in an integrated session. Official copy stresses that critical actions still need human approval.\n\nProject Perception in July was the vision and project name; the 17 November announcement is the name becoming a generally available product, with expanded agent capabilities. Public materials also tie it to an “agentic SOC” and a continuous discover–investigate–remediate loop. Which data sources are included, how it sits next to other Microsoft Security products, and which tenants can turn it on should be taken from official docs and the Ignite Book of News at the time.\n\nMicrosoft Perception is not a new general-purpose foundation model. It is a security product platform. It should also not be merged with same-week names such as Copilot Home or the MAI model family."
