intro: "**Plurai Simulation** 是 Plurai 在 2026 年 11 月 11 日正式推出的 AI agent 模拟与自我改进产品。联合创始人兼 CEO Ilan Kadar 在[官方博客](https://www.plurai.ai/blog/introducing-plurai-simulation-self-improving-layer-for-ai-agents)（日期标注 November 11, 2026）中写到：“Today we’re launching Plurai simulation, the self-improving layer for AI agents. It’s free to start for every AI engineer, and we’re announcing $13M in seed funding led by Team8.” 同日 14:30 UTC，官方账号 [@pluraiAI](https://x.com/pluraiAI/status/2120524451184001519) 与 Ilan Kadar 本人账号 [@ilan_kadar](https://x.com/ilan_kadar/status/2120524450831413518) 同步发帖宣布产品上线（公司帖措辞为 “self-improvement layer”）以及种子轮融资。\n\n按官方说明，Plurai Simulation 会从企业自己的知识库、工具和策略出发，为该 agent 及其所处世界建立数字孪生，再在沙箱中放入覆盖多种意图、人设和长尾边界情况的模拟用户，以便在真实客户看到问题之前，暴露策略违规、幻觉、错误动作、工具调用失败、任务失败和敏感数据泄漏。官方强调：发现失败还不够，模拟会对每次失败解释原因并生成修复，从而减少手工排查；同一批模拟数据还会用来对面向该 agent 的模型做后训练（post-train），官方称这能在提高能力的同时降低规模化运行成本。生产环境中，新的失败会再回流到模拟里，形成官方所说的循环：simulate, fix, post-train, repeat。\n\n产品与文档方面，官方给出产品页 [plurai.ai/simulation](https://www.plurai.ai/simulation)、文档站 [docs.plurai.ai](https://docs.plurai.ai/)，以及起步入口 [simulation.plurai.ai/connect](https://simulation.plurai.ai/connect)。文档写到，它以内嵌在已有编码助手中的方式工作，支持 Claude Code、Codex 和 GitHub Copilot；在 Claude Code 中可通过 `/plugin marketplace add plurai-ai/plurai-plugins` 安装插件，再运行 `/simulate <path-to-your-agent>`。博客还写到，团队也可以把搭建在 Salesforce Agentforce 等企业平台上的 agent 带进来。PR Newswire 通稿（2026-11-11, 09:00 ET）同步宣布 1300 万美元种子轮和平台普遍可用（general availability），并写到此前主要面向选定合作伙伴，现在向每位 agent 构建者开放，提供免费档。\n\n关于效果数字，官方博客与通稿写到：在过去数月与一部分设计合作伙伴（含 Fortune 500 和大型金融机构）合作后，agent 开发周期从数月缩短到数小时，到达真实用户的失败下降 82%，运行可靠 agent 的成本下降 97%；与 NVIDIA、Nebius 的联合工作中，Plurai 为某全球企业客户后训练的模型在准确率上超过 OpenAI 和 Anthropic 的前沿模型，成本分别约为 1/40 和 1/44。这些都是官方或通稿中的陈述，本页未做独立核验，引用时请写明来源。种子轮由 Team8 领投，U&I、Velocity、Mercer 以及二十余位天使和行业人士参与，博客点名包括 CyberArk 创始人 Udi Mokady，以及 Google Cloud 的 Reah Miyara；Microsoft 365 Copilot 的 CTO Dr. Eyal Carmi 加入顾问委员会。创始人为 Dr. Ilan Kadar 与 Dr. Elad Levi，博客称他们曾在自动驾驶领域工作，并与 Waymo 等公司有过合作。\n\n补充：本站 11 月 12 日
