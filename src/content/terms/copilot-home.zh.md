intro: "**Copilot Home** 指微软在 2026 年 11 月 17 日 Ignite 上宣布一般可用的、Microsoft Copilot 应用中的工作起点 **Home**。官方 Copilot 博客 [Copilot at Microsoft Ignite…](https://www.microsoft.com/en-us/copilot/blog/2026/11/17/copilot-at-microsoft-ignite-expanding-whats-possible-with-intelligence-built-for-work/) 把 Home 写成 Chat 与 Cowork 汇合的地方，并宣布二者现已 GA；同期 [Home: Your starting place for work in the Microsoft Copilot app](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/home-your-starting-place-for-work-in-the-microsoft-copilot-app/4573945) 则把 Home 定义为提问、委派多步任务、查看待办，以及跟踪 Copilot 正在生成和运行的工作的统一入口。\n\n在 Home 里，Auto 会为任务选择合适的模型和力度；对更复杂、需要委派的工作，Auto 也可能建议从 Chat 切到 Cowork，并带走提示词与相关上下文。官方还提到 Office 能力在 Chat 与 Cowork 中一般可用，可直接生成可编辑的 Word、Excel、PowerPoint 并保存到 OneDrive。名为 Today 的视图则把邮件、日历、Teams 等需要关注的事项带到 Home。\n\n本条记录的是这次被确认 GA 的产品表面名称 Copilot Home / Home。它不是一个新的基础模型，也不应和同场的 Microsoft Perception、MAI 模型或仍在滚动发布的 Copilot Autopilot 混为一个词。"
explain: "微软把 Home 写成 Copilot 应用里“开始工作”的那一层，而不是又一个独立的聊天机器人品牌。以前提问（Chat）和把一整段工作交出去（Cowork）更容易被拆在不同入口；这次 GA 的重点是把它们放进同一个 Home，共用历史，并用一个输入框起步。Auto 负责挑模型和力度；在 Cowork 一侧，官方还提到 Auto 使用 Microsoft-Decision-1.1 调整力度，并把复杂工作拆给并行的子 agent，这一部分当时写的是向 Frontier 用户滚动。\n\n同场还有其他 Copilot 变化：Office in Copilot 一般可用、Copilot Managed Runtime 一般可用、Code 将在数周内 GA、Autopilot 开始向 Frontier 用户推出。这些是相关但不同的名字，不应全部塞进 Home 这一条。Today 视图被写成 Home 里偏主动的指挥中心，用来汇集跨应用的待办，而不必每次都先写一句提示词。\n\n具体哪些租户已经看到 Home、Auto 或 Today，以 Microsoft 365 / Copilot 应用当时的实际界面和发布说明为准。不要把 Copilot Home 理解成要替换掉整个 Microsoft 365，它是 Copilot 应用内的起点层。"
usage: "从 [Copilot at Microsoft Ignite…](https://www.microsoft.com/en-us/copilot/blog/2026/11/17/copilot-at-microsoft-ignite-expanding-whats-possible-with-intelligence-built-for-work/) 和 [Home: Your starting place…](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/home-your-starting-place-for-work-in-the-microsoft-copilot-app/4573945) 了解定位，再到 Microsoft Copilot 应用里打开 Home。适合的用法是：在同一个输入框里先问一个问题或起草文稿（Chat），需要多步、可离开的任务时再按建议切到 Cowork，让 Auto 选模型和力度；用 Today 查看跨邮箱和会议的待办，而不是在多个入口之间来回找历史。\n\n评估时看 Chat 与 Cowork 的历史是否真的打通、从 Chat 切到 Cowork 时上下文是否还在，以及 Auto 的路由是否符合组织的模型治理策略。Office 文件会保存到 OneDrive，权限与合规仍按现有控件。\n\n若你要的是安全平台 Microsoft Perception，或 Ignite 同期的 MAI 模型，请走对应词条，而不是在 Home 里寻找它们。"
