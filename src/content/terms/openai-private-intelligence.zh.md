intro: "**OpenAI Private Intelligence** 是 **OpenAI** 于 **2026 年 10 月底**推出的**企业级隐私方案**，口号是 *“Frontier intelligence. Private by design.”*（前沿智能，隐私为本）。它把一系列控制能力打包，让企业在使用 OpenAI 最强模型的同时，限制包括 OpenAI 在内的各方对其数据的访问。\n\n两大核心是：面向符合条件 API 工作流的**零数据保留（Zero Data Retention, ZDR）**，以及基于**机密计算**、具备严格可验证控制的 **Private Inference（私有推理，预览版）**。此外还包括访问限制、审批、智能体权限、加密、客户数据所有权与合规支持，以及 ChatGPT Work 中的相应管控。"
explain: "## 要点\n\n1. **零数据保留**：符合条件的 API 请求处理后不被存储。\n2. **Private Inference（预览）**：推理在机密计算环境中运行，即使对运营方也保护数据，并提供可验证的保障。\n3. **访问与审批**：企业可限制哪些人员、应用和智能体能接触数据，并设置审批流程。\n4. **智能体权限**：智能体通过连接器、自动化执行操作时，由管理员控制其可访问与可执行的范围；ChatGPT Work 提供基于角色的访问控制和应用连接管控。\n5. **所有权与合规**：输入与输出归客户所有，并提供加密与合规支持。\n\n## 为什么值得关注\n\n“谁能看到数据”是企业和政府采用前沿模型的最大障碍之一，尤其是会接触内部系统的智能体。在开源权重模型（如可本地部署的大模型）带来的“主权 AI”压力下，Private Intelligence 是 OpenAI 给出的回应。"
