It belongs to the same Ignite model wave as MAI Code 2, MAI Cyber 2 Flash, and the already filed MAI Image 2.7, but it is a new real-time voice line rather than an alias of a text or image SKU.\n\nMicrosoft compares it with GPT Realtime 2.1 and says it outperforms that model on quality, speed, and price across public benchmarks and Microsoft product evaluations, sitting on the performance-price Pareto frontier for Big Bench Audio (speech reasoning) and τ-Voice (agentic task completion). A pricing footnote states that base speech-to-speech usage is $0.01 per minute, with reasoning billed separately at $1 per million input tokens and $5 per million output tokens.\n\nThe official getting-started path is to try it in MAI Labs or register for a Foundry limited-access preview; preview customers are not billed until public preview begins. The post also says the model is compatible with the OpenAI Realtime API, so existing voice apps can be tested and migrated more easily."
