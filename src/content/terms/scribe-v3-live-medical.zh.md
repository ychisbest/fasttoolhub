intro: "**Scribe v3 Live Medical** 是 [ElevenLabs](https://elevenlabs.io/blog/scribe-v3-live-medical) 在 2026 年 11 月 17 日发布的实时医学语音转写模型，作者为 John Durovsik。官方把它建立在已有的实时模型 **Scribe v3 Live** 之上，并针对临床用语做了优化，现已在 **ElevenAgents** 中提供。产品页 [Medical transcription](https://elevenlabs.io/medical-transcription) 的表述是：面向临床语言的两款 Speech to Text 模型——用于 ElevenAgents 的 Scribe v3 Live Medical，以及用于批量转写的 Scribe v2 Medical。\n\n发布动机写得很具体：语音智能体只能根据它听到的内容行动，而药名很容易被听错。官方举例，测试中曾有模型把降糖药 sitagliptin 转写成抗抑郁药 citalopram。ElevenLabs 已有面向录音、口述和就诊记录的医学转写，但预约、用药咨询、资格审核和理赔跟进等场景发生在实时通话里，不能等到录音结束。Scribe v3 Live Medical 被写成“our first medical transcription built for agents”，把 Scribe v2 Medical 的临床侧重带到实时对话中。\n\n本站已在 2026-11-11 收录通用的 Scribe v3 / Scribe v3 Live。不要把本词条写成那次发布的重复，或写成对 Scribe v3 Live 的一次普通参数更新；官方明确这是一个针对临床语言、用于实时通话的专用模型名称。"
explain: "官方列出了几项面向临床通话的能力：可加载最多 10,000 个自定义词（仅在调用者似乎说到其中一词时才启用）；在测试中，加载自定义词表后医学术语错误最多减少 48%。它还能识别号码尚未读完的停顿，避免智能体在会员号或出生日期中间插话；并支持 90 多种语言，可跟随患者在通话中途换语言，而不是把第二语言丢掉。\n\n评测方面，官方写明结果来自 ElevenLabs 对所选提供商实时模式的内部测试，并不包含所有模型。在 PriMock57（57 通模拟直播初级诊疗，约 9 分钟/通，未经脚本、含背景噪音）上，Scribe v3 Live Medical 的词错误率（WER）为 12.8%，在其测试的医学模型中最低，比最接近的对手少约 17% 的错误。在 Fareez OSCE（272 段患者访谈）上，它的语义 WER 在所测医学模型中最低，为 0.6%。与 Scribe v3 Live 相比，在偏医学术语和品牌药名的 Eka Medical ASR 上，语义 WER 为 11%，低于 Scribe v3 Live 的 11.54%（少 4.7% 的错误）。在 Common Voice 与 FLEURS 的英语日常集合上，它与 Scribe v3 Live 表现大致相当。MED-Term 上的语义 WER 为英语 2.24%、德语 2.81%、法语 3.24%。延迟方面，官方称 Scribe v3 Live 转写时延约 150 毫秒，Scribe v3 Live Medical 在测试中与之相当。\n\n合规上，官方写明：在已签订业务伙伴协议（BAA）并启用 Zero Retention Mode 的企业客户中，该模型符合 HIPAA 资格；它运行在 ElevenAgents 上，覆盖 SOC 2 Type II、ISO 27001 和 PCI DSS Level 1。患者数据默认存在美国，企业如需可使用欧盟、印度或新加坡的隔离环境。博客中引用了 Pfizer 的 Idin Jafari 以及 Vintage Labs AI 的 Shantanu Ghorai 的早期使用评价，这些是客户证言，不是第三方评测。"
usage: "官方起步说明：Scribe v3 Live Medical 现已在 ElevenAgents 中提供。打开 Settings > Automatic Speech Recognition，在模型下拉菜单中选择它即可。产品与合规说明见 [Medical transcription](https://elevenlabs.io/medical-transcription) 与[这篇博客](https://elevenlabs.io/blog/scribe-v3-live-medical)。\n\n适合用在药名、剂量、手术或症状等临床细节会出现的患者、会员或医护通话；官方也写到，它对日常用语的准确率与 Scribe v3 Live 相当，因此也可以用在同一条线路里的预约改期、询问开放时间等非临床通话。若团队已有面向录音或口述的流程，批量转写仍应使用产品页上的 **Scribe v2 Medical**，而不是把 Live Medical 当成离线批处理模型。需要医院、药企内部专有名词时，按官方说明加载最多 10,000 个自定义词。处理受保护健康信息时，企业客户需自行落实 BAA 与 Zero Retention Mode 等官方列出的条件。"
