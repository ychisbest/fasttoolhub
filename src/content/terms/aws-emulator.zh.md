intro: "**AWS Emulator** 是 Amazon Web Services 于 2026 年 11 月 11 日在官方新闻博客 [Test your applications against AWS locally with AWS Emulator](https://aws.amazon.com/blogs/aws/test-your-applications-against-aws-locally-with-aws-emulator/) 中宣布普遍可用的本地模拟器，作者为 Daniel Abib。博客开篇写到：Today we’re announcing AWS Emulator，一个你可以在自己机器上运行的 Amazon Web Services 本地模拟器。AWS CLI、AWS SDK 以及编码智能体通过本机 HTTPS 端点，使用与云端相同的 AWS API 与它通信。官方产品页为 [AWS Emulator](https://aws.amazon.com/products/developer-tools/emulator/)，文档为 [docs.aws.amazon.com/emulator](https://docs.aws.amazon.com/emulator/)，源码仓库为 [github.com/aws/aws-emulator](https://github.com/aws/aws-emulator)。\n\n官方写到，AWS Emulator 没有额外服务费，你只在把资源部署到 AWS 时才为 AWS 资源付费。Linux 可通过 RPM 或 Debian 包安装（包会把 `aws-emulator` 加到 `/usr/bin/`），macOS 与 Windows 则按文档中的简短 Dockerfile 构建镜像并在容器中运行；官方明确写到不发布现成镜像。启动后，它在 `127.0.0.1:9297` 提供 HTTPS，并把凭证、配置和证书写到 `~/.aws/emulator/9297/`；访问密钥 ID 以 `EMULATOR` 开头，并拒绝用其它密钥签名的请求。模拟器使用单一账户 `000000000000`。实现语言为 Rust。它支持在 GitHub 上 AWS API models 仓库中有 API 模型的那些 AWS 服务的 API，因此请求与错误的形状与 AWS 上一致。对测试，官方还提供进程内嵌入模式（`aws-emulator-embedded` crate，面向 AWS SDK for Rust），每个嵌入实例有自己的状态，便于并行测试。未实现的操作返回 HTTP 501。\n\n保真度方面，官方用“保真测试”（fidelity tests）衡量：先把短工作流在真实 AWS 上验证，再要求模拟器在每次调用的状态码、响应体、精确错误码与信息，以及工作流创建的资源与数据上都与 AWS 一致。每次发布会按服务公布通过数，形式为 k of n；测试集（包括尚未通过的）公开在 [aws-emulator-evaluation-suite](https://github.com/aws/aws-emulator-evaluation-suite)。官方提醒：新增测试时，分数也可能在模拟器改进的同时下降。构建与维护方面，博客写到模拟器由智能体根据 AWS API 模型，使用 Amazon Bedrock AgentCore Runtime Instances、AWS CodePipeline 和 AWS CodeCommit 构建并维护；一组智能体通过对比真实 AWS 与静态比对 Smithy 模型来找缺口并提单，另一组写测试、实现行为并做正确性、性能与安全审查，再进入发布流水线。因为代码由智能体编写，官方还安排了独立的安全智能体在修改过程中和发布流水线里做对抗式审查。Amazon 官方新闻 [How we built the agents that built AWS Emulator](https://www.aboutamazon.com/news/aws/how-autonomous-ai-agents-built-aws-emulator)（Matthew Goldberg，2026-11-11）写到，团队没有编写或审查其中任何代码，源码以 Creative Commons CC0 发布，议题分别放在 `issues/things-that-now-work` 与 `issues/things-that-do-not-work`。Amazon CTO Werner Vogels 于 2026-11-11T18:02:21Z [发帖](https://x.com/Werner/status/2120577888844148891)，称“AWS Emulator, launched today and written and tested entirely by agents, gives you that kind of environment for more than 200 AWS services”，并指向客座文章 https://www.allthingsdistributed.com/2026/11/aws-emulator-and-the-engineers-job-when-agents-write-the-code.html 。\n\n局限方面，官方写到它不会像 AWS 那样评估 IAM 与基于资源的策略，因此 AWS 会拒绝的请求在模拟器里可能成功；每个模拟器实例相当于单一账户，没有跨账户或跨区域行为；与 AWS 的接近程度因服务和功能而异，不要用它来测试应用是否安全，也不要把真实凭证放进测试作业环境。默认会发送匿名使用与错误数据，可以关闭。\n\n要点：\n\n- ；文档：https://docs.aws.amazon.com/emulator/ ；源码：https://github.com/aws/aws-emulator ；\n- Werner Vogels 宣布帖：https://x.com/Werner/status/2120577888844148891 （2026-11-11T18:02:21Z）；Amazon
