explain: "Amuse is not a new foundation model. Its pitch is to put a personal assistant on the user’s machine, so memories, chats and login credentials stay local instead of on Replit’s servers. The repo describes naming an agent and opening side chats; web research with sources via OpenAI’s web search; a live browser in the chat that you can watch, take over or stop; reminders, monitors and a background heartbeat that only messages you when something matters; turning goals into step-by-step plans; and documents, PDFs, images, podcasts and small space-like apps. Consequential actions raise approval cards, scoped to once, a task, a site, or always. Logins and API keys sit in an encrypted vault; the model only sees stand-in tokens.\n\nAt the time of this scan, the README listed `gpt-6.2-sol` as the default chat model, `gpt-6-luna` for quicker steps, and `gpt-image-2` for images. Those defaults follow the repo’s `.env.example` at that moment and may change. There is also an `AMUSE_DAILY_LIMIT` (2,000 usage units by default) that stops the agent for the day. The project is deliberately narrow: a web app for one person, OpenAI models only, connections through API keys and a live browser rather than MCP, and no phone push notifications yet.\n\nThe security model is equally narrow: there is no login, the server listens on `127.0.0.1` only, and it should not be exposed to a network. With Docker Compose, the browser may run without Chromium’s own sandbox, and the container is the isolation boundary. When you evaluate it, separate “Replit used Missions to build this in three days and open-sourced it” from whether the setup, cost and permissions are actually controllable on your machine."
