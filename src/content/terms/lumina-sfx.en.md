explain: "## What it does\n\nLumina SFX is aimed at a narrow gap: agents can already write games and cut video, but sound design still often means browsing a library by hand. The skill lets an agent take a natural-language description, search a local bank, layer a scene, and export WAVs—or drop editable TypeScript recipes into a project. The workflow is **offline**: WAV and TypeScript export need only Node, not a cloud audio model.\n\nThe repository describes several pieces:\n\n- **Search and scene building.** You can ask for an isolated cue such as a “thocky mechanical keyboard click,” or blend “fire crackle” with “distant thunder” into one scene.\n- **Export and engine helpers.** WAVs can go into any audio editor. Installer scripts can wire playback helpers into Web Audio / Three.js, Godot 4, Unity, Unreal Engine 5, and Python / Pygame. Web projects can also use the editable TypeScript recipes directly.\n- **CLI tools.** `choose.mjs`, `search.mjs`, `remix.mjs`, `install-sfx.mjs`, and a QA script cover search, remix, export and checks. QA writes a 44.1 kHz, 16-bit preview and inspects peak level, loudness, onset and, where relevant, loop boundaries. Ogg Vorbis and Opus need a local FFmpeg encoder.\n- **Finer sound design.** Per-layer gain, timing and design controls are documented in `SKILL.md` and the sound-design cookbook.\n\n## License (follow the repo LICENSE)\n\nThe README says you may render, modify and ship the sounds in personal or commercial games, apps, videos and demos for free, with no royalties and no required audio credit. The engine and tools are **MIT**. The sound-library license forbids redistributing, rebranding or reselling the bank or rendered collections as a competing SFX pack, sample library, training dataset or Agent Skill. The binding text is the repository [LICENSE](https://github.com/LuminaBench/lumina-sfx/blob/main/LICENSE).\n"
