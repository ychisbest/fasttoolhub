Site: https://www.merge.dev/ ; docs: https://docs.merge.dev/merge-agent-handler/overview ; launch post: https://www.merge.dev/blog/agent-handler .\n\nIn Merge's universal context stack it sits beside **Merge Unified** (customer data sync) and **Merge Gateway** (model routing / spend control), focused on agents that **act in third-party apps on behalf of end users**.\n\nHighlights:\n\n- **Registered Users**: credential containers isolated per end user or service account;\n- **Tool Packs**: governed bundles of connectors/tools that bound what an agent can reach;\n- **Security Gateway**: scans every `tools/call` input/output (standard entity rules, custom regex, natural-language guardrails) to allow, redact, or block;\n- **Connector Studio**, rules/alerts, searchable logs, Evaluations Suite;\n- Docs cite **190+** MCP-ready third-party connectors (catalog grows over time); MCP integration supported;\n- Merge states SOC 2 Type II, ISO 27001, HIPAA, GDPR (and related) compliance posture."
explain: "## Problem\n\nBare MCP servers often lack enterprise maintenance, per-user auth, fine-grained scopes, and DLP. LLMs can leak PII/secrets into tool calls; running OAuth/rotation per customer is expensive. Agent Handler handles onboarding, auth, rate limits, and errors while your LLM still does reasoning.\n\n## Call path (per docs)\n\n1. Agent lists tools from its Tool Pack;\n2. If the Registered User lacks credentials, Merge Link prompts a connect;\n3. Arguments pass the Security Gateway before the third party;\n4. Responses are scanned again, then returned—full audit trail.\n\n## Limits\n\n- Connector/tool coverage follows the live catalog;\n- Gateway rules must be configured per org/Tool Pack—not zero-risk by default;\n- Shares Link and credential store with Merge Unified API for teams already on Merge."
usage: "## Who it's for\n\n- Product agents acting for **customers** (CRM, tickets, calendar, etc.), not only internal workforce bots;\n- Teams that need least-privilege, audit logs, and DLP for compliance (customer stories include Perplexity Enterprise and Telnyx).\n\n## Getting started\n\n1. Read https://docs.merge.dev/merge-agent-handler/overview and https://www.merge.dev/blog/agent-handler ;\n2. Create a free account; register users, connectors, and Tool Packs via Get started;\n3.
