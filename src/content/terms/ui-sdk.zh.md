intro: "**UI SDK** 是 Vercel 在 2026 年 11 月 12 日正式介绍的、面向 agent 的界面行为库。官方账号 [@vercel](https://x.com/vercel/status/2120950020249895314) 于 2026-11-12T18:41:04Z（北京时间 11 月 13 日 02:41）发帖：“Introducing the UI SDK.” [@shadcn](https://x.com/shadcn/status/2120951116682682646) 于 18:45:26Z 写道：“Today we’re introducing UI SDK. Agents are becoming both the builders and the users of interfaces. So we asked ourselves: where should the abstraction live?” 他以 Select 为例，指出其中有弹出层、选择逻辑、键盘导航和焦点管理，这些行为在许多其他组件里同样有用。文档站 [ui-sdk.dev](https://ui-sdk.dev/) 的定位是：一套供 agent 用来构建下一代用户界面的行为库。\n\n按官方文档，与其把一个成品 Select 交给 agent，不如交给它组成 Select 的零件：`createPopup`、`createSelection`、`createTypeahead`。这样它不但能做 Select，还能做自动完成、组合框，甚至尚未被设计出来的组件。官方称已构建 50 多个行为，覆盖键盘导航、焦点、选择、弹出层、拖放和屏幕阅读器支持等，行为放在 `@ui-sdk/core`，再用适配器在 React、Vue、Svelte、Solid 和 Web Components 中渲染；同时提供一套由这些行为组成的无样式起步组件。安装示例是 `npm install @ui-sdk/react @ui-sdk/core`（其他框架替换对应适配包），并可用 `npx skills add vercel-labs/ui --skill ui-sdk` 给 agent 加上技能。文档还写到，agent 可以直接读取用 UI SDK 构建的控件状态并调用动作，而不必靠截图。源码在 [vercel-labs/ui](https://github.com/vercel-labs/ui)，许可为 Apache-2.0；GitHub 显示仓库创建于 2026-10-26T17:39:27Z，公开介绍集中在 11 月 12 日 18:41 UTC 前后。官方 README 写明 UI SDK 目前处于 beta，须遵守 Vercel beta 条款，框架、API、文档和行为在正式版前可能变化。\n\nVercel CEO [@rauchg](https://x.com/rauchg/status/2120966768483262648) 于 19:47:37Z 写道：UI SDK is like the x86 instruction set for agents to build new UI components spontaneously. @shadcn 稍后还表示，他们在 UI SDK 里做了一些 agentic 功能，会在随后几天展示。本词条是对 11 月 12 日官方发布的补录：宣布时间落在当日 00:32 扫描之后、04:32 窗口之内，但 04:32、08:32 和 12:32 几轮都没有把这个独立产品名入库。\n\n要点：\n\n- 官方介绍帖：https://x.com/vercel/status/2120950020249895314 ；shadcn 帖：https://x.com/shadcn/status/2120951116682682646 ；文档：https://ui-sdk.dev/ ；仓库：https://github.com/vercel-labs/ui ；\n- 这是 **Vercel 的一个具体产品名**（与已有的 AI SDK 并列的另一套库），不要和 shadcn/ui 组件库或 Vercel AI SDK 混写成同一个产品。它目前是 beta，不要写成已经稳定的 1.0。"
