intro: "**Vibe Desktop** is the official desktop app [Mistral AI](https://mistral.ai/products/vibe/) shipped on 17 November 2026. It puts the existing **Mistral Vibe** product — formerly Le Chat, with Vibe Work and Vibe Code — into one macOS and Windows application. The official account [@MistralAI](https://x.com/MistralAI/status/2122713547952324750) posted at 2026-11-17T15:28:42Z (23:28:42 on 17 November 2026, Asia/Shanghai): “Oh, and Vibe desktop is here! Hand Vibe several tasks at once, watch the agents work side by side, then review their diffs and track pull requests in the same window.” When this scan checked that post it had about 101 likes and about 8,002 impressions. An earlier post in the same thread promoted a limited free offer for Vibe in Europe and had more engagement; the desktop-app announcement itself is the post linked above.\n\nThe official [release notes](https://docs.mistral.ai/resources/release-notes) title the day’s update “Vibe Desktop: Work and Code in one app” and mark it New Release, General Availability, Mistral-Hosted. They say you can run coding tasks against a repository on your machine or in a managed cloud sandbox, keep several conversations organised, and inspect files, commands and pull requests beside the conversation. Local sessions share the Vibe CLI’s core agent engine and session logs without embedding or running the CLI application; no separate CLI install is required, and tools and prompts can differ. Linux support is coming soon.\n\nThe product pages [mistral.ai/products/vibe/](https://mistral.ai/products/vibe/) and [vibe/code](https://mistral.ai/products/vibe/code/) provide the macOS and Windows downloads (for example [macOS](https://chat.mistral.ai/download/vibe-desktop/mac?from=website) and [Windows](https://chat.mistral.ai/download/vibe-desktop/windows?from=website)). Do not describe Vibe Desktop as a new model, or as one of the earlier unofficial community wrappers; it is Mistral’s official desktop surface for the existing Vibe product line."
explain: "In the official doc [Choose CLI, VS Code, web, or Desktop sessions](https://docs.mistral.ai/vibe/code/choose-cli-vscode-web-sessions), Vibe Code has four supported surfaces: the CLI, the VS Code extension, Vibe Code Web, and Vibe Desktop. They share a core agent engine, but their runtimes, tools and prompts can differ. Vibe Desktop is the surface that keeps cloud and local sessions in one desktop app: local sessions work against a clone and your development environment, and cloud sessions use a managed sandbox and can attach a GitHub repository directly.\n\nThe 17 November release notes list these capabilities: an integrated terminal and Git worktrees for parallel changes; adding local folders to Vibe Work; coordinating sub-sessions and inspecting delegated subagent conversations; leaving builds, dev servers and file watchers running in the background, with live output and a way to stop a process; in-app browsing of repository files, Unified or Split diffs, and pull-request titles, numbers and statuses; an integrated browser for docs, issues, dashboards and pull requests; projects, pinning and archiving, plus a command palette and keyboard shortcuts; and native OS notifications. These are official feature descriptions, not third-party reviews.\n\nVibe itself is not new on this date. The product page says Vibe is Mistral’s assistant for work and code, that Le Chat is now Vibe, and that conversations, settings and plans carry over. This entry records the **Vibe Desktop** client that became generally available on 17 November, not the whole Vibe product as a new name. The same thread also promoted Vibe together with Le Chonk (already stored as Mistral Large 4) and a limited Europe free-code offer; that is a concurrent promotion, not part of the desktop app’s spec."
usage: "The [release notes](https://docs.mistral.ai/resources/release-notes) start with: download Vibe Desktop, sign in with your Mistral account, and try a focused task in Work or Code. Official downloads are on [mistral.ai/products/vibe/code/](https://mistral.ai/products/vibe/code/), with [macOS](https://chat.mistral.ai/download/vibe-desktop/mac?from=website) and [Windows](https://chat.mistral.ai/download/vibe-desktop/windows?from=website) links; Linux is not yet listed as a supported platform. After you sign in, Vibe Work and Vibe Code are available in the same window.\n\nIf you already use the CLI or the VS Code extension: the docs say those two surfaces share configuration and sessions, so you can start in one and resume in the other. Desktop local sessions share the CLI’s core engine and session logs, but tools and prompts can differ, and you do not need a separate CLI install. For terminal-first, scripted or CI work, keep using the CLI (for example `vibe --prompt`); the comparison table says Desktop has no non-interactive mode. Vibe also implements the Agent Client Protocol (ACP) for other IDEs, including JetBrains; see the official “Use Vibe in other IDEs” page. Enterprise on-prem or private-cloud deployment and fine-tuning through Mistral Forge belong to the wider Vibe product, not to Desktop alone."
