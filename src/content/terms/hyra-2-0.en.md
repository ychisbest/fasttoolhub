intro: "**Hyra 2.0** is an **AI research-agent system (AutoResearch)** released by **Tencent Hunyuan (Tencent Hy)** on **November 2, 2026**. Where the first Hyra mainly pointed general-purpose agents at individual hard research problems, Hyra 2.0 has agents **build and upgrade reusable scientific models, research workflows and software tools**, so that the output of one project keeps paying off across many later tasks.\n\nTencent frames this as the \"second half\" of AutoResearch: **moving from lottery-style sampling and repeated problem-solving to tool upgrades**. Hyra 2.0 has already published early results in protein design, molecular simulation, quantum error correction, mathematical proof, robot structure design and processor engineering, and it is now helping develop Tencent's next-generation Hy models."
explain: "## Architecture: a three-tier agent hierarchy\n\n| Tier | Responsibility |\n|---|---|\n| **Overall** | Talks to researchers; coordinates priorities, resources and key decisions |\n| **Mission** | Owns one research question long-term; plans routes, schedules experiments, judges conclusions |\n| **Worker** | Writes code, runs experiments and analyzes results in parallel isolated sandboxes |\n\n- Tasks sit in a **persistent queue**, so work continues while waiting on experiments or human approval — enabling research programs that run for **days to weeks**.\n- A **Research Board** tracks progress and requires Workers to submit evidence (code versions, results, run logs); independent **Review Workers** re-check when needed.\n- Project state, working memory and cross-task experience are stored separately; validated methods become reusable **skills**.\n\n## Published results (vendor-reported)\n\n- **HyInv** — a 1.96M-parameter protein inverse-folding model trained from scratch; better structure agreement than ProteinMPNN and **57x faster** generation.\n- **HyPLM-Flash** — a 650M-parameter protein language model trained on 726B tokens; fastest inference among 12 compared models, 3rd average rank over 35 tasks.\n- **HyFF** — an atomistic foundation model for molecular simulation in 5 sizes (2.3M–1.2B params), 83 elements, on the accuracy/speed Pareto frontier.\n- **HyQEC** — built a [[488,123,22]] quantum code, ~48% above the previous qLDPC Challenge leader on the efficiency metric.\n- **HyProver** — a proof workflow that completed proofs including Yau's circle-action conjecture, checked by mathematicians.\n- **XiangShan RISC-V** — +5.79% SPEC CPU2006 score per GHz; fuzzing and formal verification found 10 issues, with fixes contributed to the open-source OpenLLC cache.\n\n## How open is it?\n\nArtifacts (models, code, reproduction scripts) are being published on GitHub under Apache 2.0, but **the agent implementation, weights and full orchestration methodology remain closed**."
