intro: "**Gemini Decision 1** 是 Google 于 2026 年 11 月 11 日宣布的新模型，并通过 **Gemini Decisions API** 提供。官方博客为 [Gemini Decisions API: Fast, calibrated multimodal decisions](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)，作者为 Google DeepMind 产品经理 Min Choi 与首席科学家 Felix Yu。博客写到：这是一个面向封闭集决策的新端点，由新模型 Gemini Decision 1（`gemini-decision-1`）提供支持，现已通过 Google AI Studio 中的 Gemini API 开放。\n\n官方说明，Decisions API 为工具选择、策略检查、模型路由和上下文评分等有界选择提供专用原语。你可以提交一段最多 256K token 的多模态输入（文本、图像、音频、视频和 PDF），并附上最多 1,000 个相互独立的问题。Gemini Decision 1 不是逐 token 生成答案文本，而是在一次前向传播中给候选选项打分，返回概率和置信度；官方给出的端到端时延为 150–250 毫秒，定价为每百万输入 token 0.10 美元，输出 token 不计费。博客还写到，在其共享基准套件上，搭配 Decisions API 的 Gemini Decision 1 比搭配 Interactions API 的 Gemini 3.5 Flash-Lite 便宜近 5 倍；在最多 16K token 的上下文、1 到 100 个问题的范围内，模型计算的中位时延约为 50–100 毫秒，并且几乎持平。上述时延、价格对比和基准领先（含最低校准误差）均为公司表述，本页不作独立复现。\n\n问题类型方面，官方提供三种：`noul`（是/否，可附真假判定说明）、`choice`（2 到 255 个选项，返回胜出项及归一化概率）、`score`（有序量表，返回加权连续分及各级概率）。每个答案都带 0 到 1 的置信度，便于把拿不准的情况交给回退逻辑或人工复核。`input` 字段使用与 Interactions API 相同的 `Content` 块格式。官方点名 Google 内部已在使用：Gemini Notebook 用它做实时模型分层与思考级别路由（日常查询最多可降低约 40% 时延，复杂任务仍留给深度推理模型）；Stitch 的 rapid canvas 实验用它在数秒内生成可操作的产品流程线框；Google Labs 的 CC 用它从 200 多种表情中即时挑选反应；Google 搜索用它在时延预算内为 MCP 工具做对抗行为与内容检测。\n\n可用范围方面，官方写到可在 Google AI Studio 领取 API 密钥开始构建，提供免费试用档用于原型，并有 Doorstep Parcels、Speed Sketch、Find the Zoo Keeper 演示，以及 Python、JavaScript 和 REST 文档。生态集成正在向 OpenRouter、LangChain、Vercel、LiteLLM、Pydantic AI、Pipecat、LiveKit、OpenCode 以及 `google-genai` SDK 推出，Google Cloud 中的 Gemini 支持即将到来。OpenRouter 已出现 [google/gemini-decision-1](https://openrouter.ai/google/gemini-decision-1) 列表。Sundar Pichai 于 2026-11-11T18:15:20Z
