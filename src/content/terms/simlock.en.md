intro: "**Simlock** is a free, MIT-licensed open-source tool from **Callstack** (the React / React Native consultancy, via its *Callstack Incubator*). It acts as a **control plane for mobile test devices**: when you run several AI coding agents in parallel on a mobile app, each agent can lease its **own** iOS simulator, Android emulator or enrolled physical phone instead of all of them fighting over one shared simulator.\n\nThe project got broad attention on **October 30, 2026** with the release of **simlock 0.4.0** on npm and a launch post from Callstack engineer Szymon Chmal that passed 800 likes. Earlier versions (0.1/0.2) were published in August 2026."
explain: "## What problem it solves\n\nCoding agents such as Claude Code or Codex often boot their own simulators when testing a mobile app. Run several in parallel and you get chaos: agents tap into each other's devices, or the machine fills up with dozens of stray simulators (one developer reported almost 70).\n\n## How it works\n\n- **Leases**: an agent asks for a device (e.g. `--platform ios --device \"iPhone 16\"`) and gets one back, **booted and health-checked**, that no other agent touches until it is released.\n- **Auto-provisioning**: if no matching device is free, Simlock creates one; if the machine is at capacity, the request is **queued**.\n- **Warm pool & cleanup**: it keeps devices ready and cleans up abandoned ones.\n- **Physical devices**: enrolled real phones can be leased the same way.\n- **Fleet mode**: start on one Mac, then put more Macs and Linux machines behind a **gateway** with one URL.\n- **Interfaces**: CLI, **MCP server**, HTTP API and a Node.js client, so it plugs into most agent setups.\n\n## Status\n\n- License: MIT, free forever per Callstack.\n- Runs on macOS and Linux; Windows support was described by the author as \"on the way\"."
usage: "## How to try it\n\n```bash\nnpm i -g simlock\nsimlock doctor          # check your Xcode / Android SDK setup\nsimlock lease --platform ios --device \"iPhone 16\"\n```\n\n- Docs: [callstackincubator.github.io/simlock](https://callstackincubator.github.io/simlock/docs/introduction)\n- Source: [github.com/callstackincubator/simlock](https://github.com/callstackincubator/simlock)\n\n## Tips\n\n- Expose it to your agent through the **MCP server** so the agent can lease and release devices by itself.\n- For teams or CI, run workers on several machines and point agents at the **gateway**.\n- Always release leases at the end of a task so the warm pool stays healthy."
