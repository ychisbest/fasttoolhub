explain: "The official site lists these capabilities: it mounts like an ordinary drive on macOS and Linux; agents in the cloud that do not have a local filesystem can reach the same files over MCP; a save lands on every Mac and every sandbox at once; one agent can write a file and the next can read it, without a separate handoff API. File primitives such as .csv are described as being treated like databases in the cloud, so row changes merge instead of conflicting. When two edits do not overlap they are merged; when they do, both versions are kept. Large files appear at full size but only the bytes a program actually reads or writes are transferred. Deleted files stay in the trash for an hour, and the service is backed up hourly. The page names Claude, Codex, Cursor, Gemini, Copilot, OpenCode, Ollama, and custom scripts, with the rule that anything that can read a file works out of the box. Cloud jobs can be given a sandbox token, lasting from 5 minutes to 12 hours, for one drive or one folder, and the token can be revoked at any time.\n\nOn pricing, the site says Personal is for one person and Team is for working together, that plans include storage and compute during early access with no automatic overage charges, and that agents do not need a seat—you pay for people. The page at the time of this scan said it is free for one person with no card required, and that Team is $25 per paid seat for the first month, then $50 per paid seat a month, along with a “Then $20 / month” line. Exact plan tiers, extra storage, and prepaid credits follow the live official page. These are product claims, not measurements by this radar."
