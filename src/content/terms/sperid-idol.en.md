intro: "**Idol** (here listed as **Sperid Idol** to distinguish it from the common word) is an open-source **image-to-3D** model from **Sperid Labs**, published on Hugging Face on **October 28, 2026** and trending there by October 31. It turns **a single picture of an object into a 3D Gaussian splat** — including the sides the picture never showed.\n\nOutput is a standard **3DGS `.ply`** file with up to about one million Gaussians, and the model runs on consumer GPUs (about **7.2 GB VRAM**, under **2 seconds** per object). It is released under **Apache-2.0** with an inference SDK, a Hugging Face demo Space, and a hosted endpoint on fal."
explain: "## Key points\n\n- **Task**: single image → 3D Gaussian splatting (3DGS). Works with photos, renders or AI-generated images.\n- **Pipeline**: automatically removes the background, frames the object, then predicts up to **1,048,576 Gaussians**.\n- **Speed & hardware**: ~7.2 GB VRAM, under 2 s on a consumer GPU.\n- **Encoders**: reads the image through two gated models — Meta's **DINOv3** (ViT-H/16+) and the **FLUX.2-dev VAE** — so you must accept their licenses on Hugging Face first.\n- **License**: Apache-2.0 for Idol itself.\n- **Ecosystem**: code at `speridlabs/idol-sdk` on GitHub (~200 stars in its first days), demo Space `speridlabs/idol`, and `fal.ai/models/speridlabs/idol` for API use.\n- **Traction**: one widely shared demo turned IKEA product photos into 3D splats via Idol and Hugging Face agents (180+ likes on X).\n\n## Why it matters\n\nGaussian splats are quickly becoming a standard 3D format for web viewers, games and AR. A fast, open, single-image model makes it practical to turn catalogue photos or generated concept art into 3D assets at scale."
