intro: "**Product Hunt MCP** is Product Hunt’s official Model Context Protocol server, launched on 9 November 2026, so agents you already use—Claude, ChatGPT, Codex, Cursor, VS Code, Gemini CLI, and others—can discover launches, research products, and draft, check, preview, and submit a launch. The human install page is https://www.producthunt.com/mcp/install .\n\nThe server URL is `https://mcp.producthunt.com/mcp` over Streamable HTTP. Auth is OAuth with PKCE. Clients identify themselves with OAuth Client ID Metadata Documents (CIMD) or register via Dynamic Client Registration (DCR); there is **no API key**. In clients that support remote MCP and that OAuth flow, the server name is typically `producthunt`.\n\nHighlights:\n\n- Launch: start a draft, add images, find what is missing, preview the result, and submit when you confirm; you can still edit or reschedule after submit;\n- Discover: search launches, browse categories, and inspect the leaderboard for a given day, week, month, or year;\n- Research: read product profiles with makers, pricing, ratings, and review highlights, and find alternatives;\n- Submit, edit, and reschedule each begin with a preview of the exact change; the server tells the assistant to show you that preview and wait for confirmation;\n- In this radar window, CEO Rajiv Ayyangar and Ryan Hoover posted about the launch, and it ranked near the top of Product Hunt that day."
explain: "## Why it matters\n\nResearching or launching on Product Hunt used to mean bouncing in and out of the website admin. The same work can now happen inside a coding or writing assistant you already have open. If you track launches, compare products, or prepare your own listing, an official MCP server is a better default than an unofficial scraper or a stale third-party integration: it uses OAuth instead of making you copy an API key, and it treats write actions such as submit as preview-then-confirm.\n\nAccess is also spelled out. The server can see your profile and the drafts and launches you can manage as a hunter, maker, or team member; product search, reviews, and the leaderboard use public Product Hunt data. That means an assistant can both research other products and, after you approve, operate your own launch—not merely run read-only search.\n\n## Limits\n\nA connection requires a client that supports remote MCP and OAuth sign-in via CIMD or DCR. The official install page covers Claude Code, Codex, Gemini CLI, VS Code, Cursor, Claude, ChatGPT, Amp, and opencode; other tools should follow the generic JSON example on that page. The server tells the assistant to show a preview and wait before submit, edit, or reschedule, but you should still read the preview yourself. Connecting MCP does not make content writable beyond your Product Hunt permissions. This entry does not invent unpublished rate limits or paid tiers."
