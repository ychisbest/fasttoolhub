explain: "官方把 Neon 放在 Gemini 4 家族里的中间档：Carbon 负责最难、最长程的项目，Hydrogen 负责日常快速执行，Neon 则强调在复杂、高频工作流里把深度和效率放在一起。定价方面，官方给出每百万输入 token 3 美元、缓存输入 0.15 美元（官方称 95% 折扣）、每百万输出 token 15 美元，上下文窗口 100 万 token。博客称，在默认 high 思维档下，Neon 的 Artificial Analysis Intelligence Index 分数配合比 Carbon 低 32% 的每任务成本；xhigh 档给出其最高智能分数，并称仍比竞品最高档每任务成本低 36% 以上。这些是公司表述，不是本雷达的独立复测。\n\n博客列出的部分官方数字包括：Artificial Analysis Intelligence Index 在 xhigh 档为 61 分，总榜第 3；Vals Index 第 2（70.9%），并称落在帕累托前沿；新的 Agent Arena Index 上可操纵性（steerability）第 2，全球得分 1336（基于 4200 多场真实 agent 会话）。编码方面，官方称 Artificial Analysis Coding Agent Index 总分第 1（58.6），Terminal-Bench 4.1 为 65.2%，FrontierCode 2.0 在默认 high 档为 46.2%；SWE-sweep 在 mini-SWE harness 上为 12.8%，在 Google Antigravity 中为 39.0%。科学与数学方面，官方给出 Terminal-Bench Science 70.5%、RiemannBench 84.0%、HLE-Diamond 71.3%。模型卡还把部分结果与 Claude Opus 5.5、GPT-6.2 Sol 并列，并另给出 CursorBench 4.1 为 65.4%（对比表中 Claude Opus 5.5 为 58.1%）。引用这些数字时请写明来源是 2026-11-18 官方博客或模型卡。\n\n在 Antigravity 里，官方称 Neon 既可单独做长程、工具密集的任务，也可作为较快的高判断 Orchestrator，调度并行的 Hydrogen 子 agent。博客还介绍了 “Gemini 4 Neon for cyber”：面向安全编码、渗透测试、漏洞发现、验证与修补，将在随后几天向 Fairwind Program 的受信任防御者开放。安全方面，官方称沿用 Gemini 4 安全与安全栈，并保持与 Carbon 相当的严重滥用和提示注入防护；完整 Safety & Security Report 官方写到“将在未来几天提供”。\n\n可用范围以官方“Start building”一节为准：开发者可在 Google AI Studio 与 Android Studio 的 Gemini API 付费档使用，付费 Pro / Ultra 订阅者可在 Antigravity 和 AI Studio 中试用；企业可在 Gemini for business（API 或模型下拉框）和 Antigravity 中使用；消费者若为 Google AI Pro 或 Ultra 订阅者，可在 Gemini 应用的模型列表中选择；网络安全场景需通过 Cloud 客户团队申请 Fairwind Program。输入支持文本、图像、音频和视频，模型卡写明合并输入输出上下文最多 100 万 token，默认同步输出最多 64K，后台长解码最多 100 万。"
