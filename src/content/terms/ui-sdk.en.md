intro: "**UI SDK** is the agent-facing interface behavior library Vercel formally introduced on 12 November 2026. The official account [@vercel](https://x.com/vercel/status/2120950020249895314) posted “Introducing the UI SDK.” at 2026-11-12T18:41:04Z (02:41 Beijing time on 13 November). [@shadcn](https://x.com/shadcn/status/2120951116682682646) wrote at 18:45:26Z: “Today we’re introducing UI SDK. Agents are becoming both the builders and the users of interfaces. So we asked ourselves: where should the abstraction live?” He used a Select as the example, noting that it contains a popup, selection logic, keyboard navigation, and focus management, and that those same behaviors are useful in many other components. The documentation site [ui-sdk.dev](https://ui-sdk.dev/) describes it as a library of behaviors for agents to build the next generation of user interfaces.\n\nAccording to the official docs, instead of handing an agent a finished Select, you give it the pieces that make one: `createPopup`, `createSelection`, and `createTypeahead`. From those it can also build an autocomplete, a combobox, or a component that has not been designed yet. The company says it has built 50+ behaviors covering keyboard navigation, focus, selection, popups, drag and drop, and screen-reader support. Behaviors live in `@ui-sdk/core`, with adapters for React, Vue, Svelte, Solid, and Web Components, plus a starter set of unstyled components built from the same pieces. The documented install is `npm install @ui-sdk/react @ui-sdk/core` (swap the adapter package for other frameworks), and you can add the skill with `npx skills add vercel-labs/ui --skill ui-sdk`. The docs also say an agent can read component state and call actions directly, without screenshots. Source code is at [vercel-labs/ui](https://github.com/vercel-labs/ui) under Apache-2.0; GitHub lists the repository as created at 2026-10-26T17:39:27Z, while the public introduction clustered around 18:41 UTC on 12 November. The official README says UI SDK is in beta and subject to Vercel’s beta terms; the framework, APIs, documentation, and behavior may change before general availability.\n\nVercel CEO [@rauchg](https://x.com/rauchg/status/2120966768483262648) wrote at 19:47:37Z that “UI SDK is like the x86 instruction set for agents to build new UI components spontaneously.” @shadcn later said the team had built additional agentic features into UI SDK and would show them in the coming days.
