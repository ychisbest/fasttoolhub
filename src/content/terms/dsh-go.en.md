Its tagline is \"DeepSeek Harness in your pocket: run it on the phone, or remote-control your computer.\" Version **1.0 shipped on October 30, 2026**, followed by rapid point releases up to **1.0.7 on October 31**, and the repo jumped to **about 3,600 GitHub stars and 160+ forks** within two days, reaching GitHub Trending.\n\nIt is an **unofficial, community-built** client made by the author of dsh-gui, not a DeepSeek product. Models are called through your own configured API. The app is written in **Flutter**, licensed **AGPL-3.0**, supports **Android 8+**, and the author says iOS and HarmonyOS ports are planned."
explain: "## Key features\n\n- **Run locally on the phone**: the app installs a bundled Ubuntu + Node.js environment and DSH itself — no root and no Termux required — so the agent can run code and handle files on-device.\n- **Remote control your computer**: switch to a DSH instance on your PC or server with one tap and keep coding while you're away; a Mac port of the client was also shared.\n- **Native mobile UI + web view**: a native chat interface with one-tap switching to the official DSH web UI on the same conversation.\n- **Steer mid-reply**: interject or queue messages while the agent is responding; finished tool steps collapse into one line.\n- **Mobile Use**: native phone-screen control, plus support for official DSH plugins.\n- **Share cards and replays** of conversations, and animated desktop pets (\"Deepy\" and \"鲸娘\") that show agent status.\n\n## Context\n\nDSH Go is part of a fast-growing ecosystem of third-party clients around DeepSeek Harness (alongside apps such as Mika). Because it is unofficial and handles API keys, commentators advise reviewing the code before granting it credentials. Android 12+ background-process limits can affect heavy Linux workloads."
