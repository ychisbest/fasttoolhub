intro: "**agent-desktop** is an open-source command-line tool from **Vercel Labs**, publicly launched on **October 31, 2026 (Beijing time)**, that gives any AI agent reliable **computer use on the desktop**. It is the sibling of Vercel's **agent-browser**: where agent-browser drives web pages, agent-desktop drives **native applications** on macOS, Windows and Linux.\n\nInstead of guessing from screenshots, it reads each app's real UI structure through the operating system's **accessibility tree**, so element references stay stable and actions are safe to retry. It is written in **Rust** and installed with `npm i -g agent-desktop`."
explain: "## What makes it different\n\n- **Accessibility tree, not pixels**: agents see a structured list of buttons, fields and menus with stable refs, which is cheaper in tokens and far more reliable than screenshot-based clicking.\n- **Drill-down**: an agent can inspect just part of a window to save tokens.\n- **Parallel & background**: it runs headless by default, so agents can work in the background while you keep using the machine, and many agents can operate one app at once.\n- **Cross-platform**: macOS (needs Accessibility permission — `agent-desktop permissions --guide`), Windows, and Linux (needs `at-spi2-core`).\n- **Cloud option**: you can start a Linux desktop in a **Vercel Sandbox**, run agent-desktop inside it and get JSON back.\n- **E2E testing**: Vercel pitches it for end-to-end testing of desktop apps with agents as well as general automation.\n\n## Context\n\nThe GitHub repo `vercel-labs/agent-desktop` existed earlier in 2026 (about 1.8k stars at launch), but the public \"Introducing agent-desktop\" launch by Chris Tate and Guillermo Rauch happened on Oct 30–31, 2026. Paired with agent-browser, it gives an agent computer use across both the web and native desktop apps."
usage: "## Getting started\n\n1. Install: `npm i -g agent-desktop`.\n2. Grant permissions: on macOS run `agent-desktop permissions --guide` and allow Accessibility for your terminal; on Linux install `at-spi2-core`.\n3. Let your coding agent (Claude Code, Codex, Cursor, etc.) call the CLI: list windows, read an app's accessibility tree, then click / type using the returned refs.\n4. Combine with `agent-browser` when a task spans both web pages and native apps.\n5. For isolation, run it inside a Vercel Sandbox Linux desktop instead of your own machine.\n\nRepo and docs: [github.com/vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop) · [agent-browser.dev/desktop](https://agent-browser.dev/desktop).\n\nTip: avoid logging sensitive accounts into a desktop that an agent controls."
