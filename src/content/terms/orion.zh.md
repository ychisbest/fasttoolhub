intro: "**Orion** 是 [Paradigm Machines](https://www.paradigmmachines.ai/) 在 2026 年 11 月 16 日公开介绍的视线预测基础模型，以及配套的网站体验分析产品 **Orion Hosted**。创始人 Ryan Lin（[@_ryanlin10](https://x.com/_ryanlin10/status/2122374141131002087)）于 2026-11-16T17:00:01Z（北京时间 2026 年 11 月 17 日 01:00:01）发帖：“Introducing Orion, a foundation model that predicts where you look. Orion finds twice as many UX bugs as frontier models, cuts computer-use latency by 31%, and even won a drone race.” 本轮核对原帖时约 1,518 次点赞、76 次转帖、约 4.9 万次展示、1,372 次收藏。该介绍发生在当日 04:32（北京时间）扫描窗口内，但当时未被入库，本轮在核对该帖与官方产品页后补录。\n\n托管产品入口为 [app.paradigmmachines.ai](https://app.paradigmmachines.ai/)，标语是 “See your site through your visitors' eyes.” 产品页写到：光标移动、滚动和停顿会泄露访客在看哪里；Orion 的模型在真实眼动数据上训练，可从你已有的 session replay 里预测这种注意力。官方条款（[Orion Hosted terms](https://app.paradigmmachines.ai/terms)，版本日期 2026-11-16）把服务提供方写成 Paradigm Machines, Inc.（特拉华州公司，从英国伦敦运营），并说明网站主可在页面中加入一段脚本（Tag），或导入 PostHog、Mixpanel、Datadog、Sentry 等工具已有的录屏；控制台展示访问、回放、预测视线，以及每次访问的 friction score。隐私政策同日生效，联系邮箱为 ryan@paradigmmachines.ai。\n\nRyan Lin 在跟帖中还提到：模型是针对人类交互单独训练的，不同于通用大语言模型；在增加数据与算力后，他们称出现了能理解 design taste 的 “visual world model”；正在做 API 和一篇技术博客；也训练了 full duplex realtime checkpoint。演示页在 [paradigmmachines.ai/demo](https://www.paradigmmachines.ai/demo)。不要把它和 Apple 或其他同名 Orion 硬件/模型混为一谈。"
explain: "Orion 做的不是普通点击热力图。官方产品页写得很明确：通用热力图工具往往映射的是光标和点击，而手会落后于眼睛、在阅读时停住，并且到不了大部分实际被看到的区域。Orion 从每一次回放里逐刻预测访客看过哪里——滚动和停顿提示正在阅读的内容，页面布局则把视线引向标题、图片和按钮。\n\n模型训练数据是采集到的眼动：人们在浏览、搜索、阅读和打字时真正看过的位置。页面举例说，点击前约三秒，眼睛会先于指针到达链接。Orion 再用眼动研究里与困难相关的四种模式检查视线，并汇总成每次访问的 friction score，同时标出背后的页面元素；分数可跨访问累加，用来比较 A/B 测试的不同版本。这四种模式是：行动前看向别处、回到已经用过的内容、眼睛与指针离得较远，以及对按钮或表单控件的长时间注视。\n\n官方介绍帖给出的三项作者声明（发现的 UX 问题约为前沿模型的两倍、computer-use 延迟下降 31%、还赢过一场无人机比赛）来自原帖，公开材料没有完整给出评测规模与对照设定，应视为官方主张而非第三方复现结果。跟帖与转述还提到：把预测热区放大、周边缩小，可减少送进视觉模型的图片 token（有转述称约 66%）；以及用低预测视线密度区域来标记提示注入、作者称可减少 96% 攻击。这些同样是作者侧的演示/声明。Ryan Lin 还把 Attention insight 与 Orion 做了区分：前者生成静态注意力图，并不使用跨时间的点击、滚动或鼠标数据。\n\n对编码代理，产品页强调三条输出：每个元素上的注视时间（一次访问或某页的全部访问）、任一时刻叠了视线的屏幕画面，以及指向具体横幅、按钮或字段的定位，好让代理知道该改哪段代码。数据也可下载：回放（rrweb JSON）、分数（JSON / Parquet）、视线（NumPy）、元素框，以及 WebM 视线视频。"
usage: "官方提供两条输入路径。一是在每个页面加入一行 Tag，记录回放、点击、滚动和页面变化，单页应用也包括在内，表单字段会脱敏。二是连接已有录屏：产品页写到可登录 PostHog，由 Orion 自行读取并像 Tag 访问一样打分，不必再往站点加代码；也可以导入最多 89 天的导出。条款还提到 Mixpanel、Datadog、Sentry 等来源的 Imported Recordings。\n\n输出同样有两条。一条是把 Orion 当作远程 MCP 服务器接到 AI 代理，地址为 `https://app.paradigmmachines.ai/mcp`，用 Google 登录，无需复制 API key。产品页给出的示例包括：\n\n- Claude Code：`claude mcp add --transport http orion https://app.paradigmmachines.ai/mcp`，然后在 Claude Code 里输入 `/mcp` 并登录。\n- Codex：`codex mcp add orion --url https://app.paradigmmachines.ai/mcp`。\n- ChatGPT：在插件里添加自定义 MCP 服务器，名称填 Orion，地址同上。页面写到需要 ChatGPT Business、Enterprise 或 Edu，或仅只读工具时的 Pro；Business 计划需由管理员添加。\n- Cursor 与 VS Code：用产品页上的相应链接添加后登录。\n\nRyan Lin 在 2026-11-17 的回复里还提到，可通过 MCP 调用 `add_site`，并且控制台新加了再添加一个站点的功能；API 仍在制作中。另一条路径是下载每次访问的数据文件，自行分析。官方称若试用不满意，会在 24 小时内处理问题，也可发邮件到 ryan@paradigmmachines.ai。演示与产品入口分别是 [paradigmmachines.ai/demo](https://www.paradigmmachines.ai/demo) 和 [app.paradigmmachines.ai](https://app.paradigmmachines.ai/)。"
