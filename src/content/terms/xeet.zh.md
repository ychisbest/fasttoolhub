intro: "**xeet** 是 Vercel CEO Guillermo Rauch（[@rauchg](https://x.com/rauchg/status/2122184794209714368)）在 2026 年 11 月 16 日正式介绍的 X 帖渲染器：用安全 Rust 和 WebAssembly 把帖子画成与 Chrome 在 x.com 上所见对齐的 PNG，而不必启动浏览器。介绍帖发出时间为 2026-11-16T04:27:37Z（北京时间 12:27:37），以 “Introducing 𝚡𝚎𝚎𝚝” 开头，并指向演示站 [xeet-rs.vercel.app](https://xeet-rs.vercel.app)。帖中写到：“A hermetic, pixel-perfect X post renderer in safe Rust / wasm. Zero browser, network, filesystem, system fonts. Renders a post to PNG in ~1ms (and 0.4 ms for @jack's \\\"setting up my twttr\\\").”\n\n官方页面把产品写成：把帖子或一条 `x.com` 链接交给它，即可得到 Retina PNG，行距、emoji、回退字体和 “Show more” 的位置都按 X 客户端规则对齐。文档强调，多数预览工具会启动无头 Chromium 再截图；xeet 则重写帖子实际依赖的部分，包括 X 的客户端规则、Blink / HarfBuzz 文本排版、文本周围的 flexbox 几何，以及 Skia 风格抗锯齿，并且核心标为 `#![forbid(unsafe_code)]`。它以一个原生二进制和一个 WebAssembly 核心发布，外加主机首次使用时注册的字体包；官方称文本帖在 390 px、3× 下 p50 渲染约 2.8 ms，带四个媒体占位时约 4.5 ms，渲染不依赖网络、文件系统、时钟和系统字体，并且原生与 WASM 构建输出相同字节。\n\n源码在 [rauchg/xeet](https://github.com/rauchg/xeet)，许可为 Apache-2.0；GitHub 记录仓库创建于 2026-11-15T18:07:57Z。官方文档给出的安装与调用包括 `npm i @xeet/core`、`npm i -g @xeet/cli`，以及 `cargo install --git https://github.com/rauchg/xeet xeet-cli`。CLI 示例为 `xeet render post.json --width 390 --theme dark --dpr 3 -o post.png`，也可用 `xeet resolve` 把 `x.com` 链接解析后再渲染。npm 上 `@xeet/core` 与 `@xeet/cli` 的 0.1.0 版本发布时间约为 2026-11-15T21:28Z。本轮 12:32 扫描核对仓库时，GitHub 仍显示 0 star；公开“Introducing”以 04:27:37Z 的介绍帖为准。\n\n要点：\n\n- 官方介绍帖：https://x.com/rauchg/status/2122184794209714368 ；演示与文档：https://xeet-rs.vercel.app ；仓库：https://github.com/rauchg/xeet ；\n- 这是 **Rauch 个人开源的一个具体工具名**，不要和口语里把 tweet 写成 xeet 的用法混为一谈，也不要写成 mohitsharmadl/xeet 或 Sigarikafat/Xeet 那些“在终端发 X 帖”的同名 CLI。官方标明 Chirp 等平台参考字体仍受上游条款约束，不在 Apache-2.0 覆盖范围内；对外发布二进制时需使用有权分发的字体，或由宿主机器提供字体。"
