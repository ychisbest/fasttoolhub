intro: "**WALL-OSS-1.0** 是深圳具身智能公司 **X Square Robot（自变量机器人）** 发布的视觉-语言-动作（**VLA**）基础模型，口号是 “Understand More. Act Better.”。2026 年 11 月 23 日 15:30（北京时间，对应 07:30 UTC），官方账号 [@XSquareRobot](https://x.com/XSquareRobot/status/2124767551959757162) 发帖宣布推出；同日 GlobeNewswire 通稿（02:44 ET）给出更完整的技术与评测说明。官网介绍：[x2robot.com/en](https://x2robot.com/en)。通稿：[GlobeNewswire，2026-11-23](https://www.globenewswire.com/news-release/2026/11/23/3408046/0/en/x-square-robot-introduces-wall-oss-1-0-understand-more-act-better-a-native-foundation-model-for-the-physical-world.html)。\n\n官方强调，它采用 **native VLA pretraining**：不是先训练视觉-语言模型、再后接机器人动作，而是从 **Qwen3.5** 基座出发，把语言、视觉-语言和机器人动作数据放进同一套预训练。通稿还介绍了改进的动作分词器、用于生成连续控制指令的 **flow-matching Action Expert**，以及让动作衔接更平滑的 real-time chunking。产品线包含 **Lite、Nano、Gen、AR** 等变体。前代是已存在的 **WALL-OSS-0.5**。\n\n同一发布还带出两个配套产品：用于把高层规划接到真机执行的智能体框架 **XR Harness**（开发者预览），以及面向开发者与企业的接口 **WALL-API-1.0**。官方在 16:07（北京时间）另发帖称 WALL-API-1.0 现已开放，用于通过 API 调用 WALL-OSS-1.0。需注意：通稿中的真机与仿真数字均为厂商自报；截至宣布时，Hugging Face 上公开的主要是更早的 **WALL-OSS-1.0-Lite RoboDojo** 预览权重，并不等于通稿里 312 项真机评测所对应的完整 1.0 权重，参数量与 API 定价也尚未公布。\n"
explain: "## 要解决什么问题\n\n通稿指出，语言模型和视觉模型已经较强，但把理解稳定地变成物理动作仍是机器人学的难点。许多现有 VLA 先做视觉-语言预训练，再补机器人动作。WALL-OSS-1.0 想通过从预训练阶段就把视觉、语言和动作放在一起学，让能力更容易迁移到没见过的任务与环境，而不是为每个新场景单独微调一套策略。\n\n## 官方给出的技术要点\n\n- **训练路径**：以 Qwen3.5 为基座做 native VLA 预训练；改进的 action tokenizer 把连续机器人运动编成紧凑的离散 token；训练目标除模仿示范外，还包括理解动作、评估候选行为与纠错。\n- **动作生成**：flow-matching Action Expert 根据视觉与语言上下文生成连续控制指令，并用 real-time chunking 保持动作连贯。\n- **指令层级**：通稿称机器人轨迹按任务、子任务、动作、片段四层标注，使模型既能跟广义目标，也能跟对物体、位置和运动的精细约束。这为 **XR Harness** 用自然语言调度操作技能提供了基础。\n- **配套系统**：**XR Harness** 分三层——System 2 负责理解目标、规划并按反馈改计划，System 1 协调执行（由 WALL-OSS-1.0 生成动作并检查完成情况），System 0 通过 Robot Agent Protocol（RAP）对接控制器与传感器。**WALL-API-1.0** 则把模型能力以接口形式开放给开发者。\n\n## 官方自报评测（须视为厂商数据）\n\n- 开放式真机：评测人员自选 312 项未见过的任务（陌生物体、工具使用、双臂协作、多步操作等），在不加任务示范或微调的情况下，通稿给出 **55.1%** 零样本成功率。\n- 仿真 **X2Real**（40 余项推理与操作任务，参评模型在同一仿真数据上微调）：WALL-OSS-1.0 总分 **67.55 / 100**，较通稿所称最强开源基线 **Lingbot-VLA-2.0** 的 40.94 提高 65.0%；在分布外移动操作上均分 44.17，对比 π0.5 的 24.83。\n- 公开 **RoboDojo** 仿真榜：截至 2026 年 11 月 5 日，紧凑版 **WALL-OSS-1.0-Lite** 在“不带智能体系统的策略”中排名第一，总分 42.59。\n- 真机 **ManipArena**（15 项桌面任务）：预训练后、不做任务微调即得到 **1,101 / 1,500**，通稿称较前代 WALL-OSS-0.5 高 52.5%，较多任务微调的 π0.5 高 70.8%；15 项中 14 项领先或并列，总体成功率 50.67%，对比 0.5 的 19.33% 和 π0.5 的 24.0%。\n\n这些数字都来自公司通稿，尚未见到独立复现，不能外推到任意场景。完整 1.0 系列权重、参数量和定价在宣布时尚不完整。\n"
