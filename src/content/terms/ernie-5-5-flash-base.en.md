intro: "**ERNIE-5.5-Flash-Base** is Baidu's **pre-training checkpoint** for the ERNIE 5.5 Flash line, publicly announced on **2026-11-05**. It is a sparse **Mixture-of-Experts** language model with **280B total / ~14B active parameters per token**, trained from scratch on **33.5T tokens**.\n\nBaidu stresses this is the **end-of-pretraining Base** — no mid- or post-training — intended as a starting point for domain adaptation, instruction tuning and RL research. Weights ship on Hugging Face as `baidu/ERNIE-5.5-Flash-Base` (FP8) and `baidu/ERNIE-5.5-Flash-Base-BF16`, with SGLang and vLLM cookbooks. The full chat/reasoning **ERNIE 5.5 Flash** is described as coming later."
explain: "## What problem it solves\n\nBaidu's ERNIE line has been mostly closed API; the community lacked a large, efficient base to fine-tune. ERNIE-5.5-Flash-Base hands developers a **high-capacity, sparsely activated MoE** they can SFT/RL on their own data without pretraining from scratch.\n\n## Architecture highlights (model card)\n\n- 43 layers (1 dense + 42 MoE); hidden size 4096; ~201K vocabulary.\n- Hybrid attention: mostly **HCA** (heavily compressed attention) with some **MLA-DSA** layers for long context.\n- MoE: 512 routed experts (top-10) + 1 shared; ~0.36B ECHO speculative-decoding params excluded from headline counts.\n- Context: up to 128K in training; configs enable **1M** for fine-tuning/inference.\n\n## License and limits\n\n- Custom **ERNIE 5.5 Flash Base Model License** (not Apache): territorial exclusions (e.g. EU/UK/South Korea); commercial use above ~US$50M related revenue needs separate authorization and “Powered by ERNIE” attribution.\n- This is a **Base**, not a chat model; Baidu's same-size evals should be independently checked.\n- Serving needs large GPU pools and a tuned inference stack."
