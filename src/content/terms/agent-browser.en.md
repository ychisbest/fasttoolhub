explain: "## Why it matters\n\nFeeding a full DOM or a large JSON tree into an agent is expensive and makes it easy to click the wrong node. Agent Browser returns a compact text accessibility tree—about 200–400 tokens versus about 3,000–5,000 for a full DOM, according to the site—and stamps each element with a stable ref so later `click` and form commands point at the exact node from that snapshot. For Claude Code, Cursor, Codex, or any other agent that already runs shell commands, that is a path that does not require wrapping Playwright yourself.\n\nVercel Labs shipped it as a cross-platform native CLI rather than an IDE-only plugin, so it can sit inside different agent harnesses. Showing up on both GitHub’s daily and weekly trending lists in this window is a clear signal that agents need a browser tool whose output was designed for them.\n\n## Limits\n\nIt expects Chrome/Chromium in the environment where the agent runs, and the first use needs `agent-browser install`. By default the daemon saves configured restore state, closes its headless browser, and exits after an hour without commands or dashboard input. Without `--restore` or another restore key, shutdown discards transient browser state and open tabs. Headed browsers, Safari and iOS WebDriver sessions, and user-attached browsers are exempt from that default timeout; provider-owned cloud browsers are not. Tune it with `--idle-timeout` or `AGENT_BROWSER_IDLE_TIMEOUT_MS`, or set `0` to disable the timeout. First-class notes for React, Web Vitals, and Next.js + Vercel do not mean it can bypass every anti-automation or login wall. It is also not the desktop-OS product covered by Agent Desktop. The star count is a scan-time observation."
usage: "1. Install the CLI with `npm install -g agent-browser` or `brew install agent-browser`, then run `agent-browser install` to download Chrome. To try it once: `npx agent-browser open example.com`;\n2. A typical loop is `agent-browser open example.com`, `agent-browser snapshot -i` to get a tree with `[ref=e1]` handles, `agent-browser click @e2` (or other commands) to interact, `agent-browser screenshot page.png` if needed, and `agent-browser close` when finished;\n3. Give it to any agent that can run shell commands (Claude Code, Cursor, Codex, Gemini, opencode, and similar) and have the model snapshot first, then use refs instead of guessing CSS selectors;\n4. For longer jobs, read the site’s notes on sessions, profiles, `--restore`, and idle timeout. Docs and releases live at https://agent-browser.dev ."
