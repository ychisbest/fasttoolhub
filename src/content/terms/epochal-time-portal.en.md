explain: "## What the company claims\n\nEpochal treats forecasting as a core test of intelligence, but says that applying today’s agents to forecasting is muddled by time-gating, information coverage, and knowledge cutoffs. Time Portal is its first answer: a point-in-time agentic web environment that uses time as a universal verifier.\n\n- **Search and fetch**: the product is powered by an index of archived pages. Search is natively time-aware, with time-gating as a first-class feature. A single URL can map to multiple historical versions, forming a version chain or changelog; on the most dynamic pages, version granularity is at the minute, and the system adapts to queries and usage.\n- **Sandbox**: time-gated web tools are not enough on their own—an agent in a sandbox can run `date` or inspect the filesystem and see that the clock is wrong. So the company built **Time Portal Sandbox**, a time-gated Linux microVM. At the kernel layer, the system clock is set to the as-of instant. The sandbox boots the Ubuntu version that existed at that instant, with contemporaneous system libraries, language runtimes, and command-line tools. Package mirrors such as `pip`, `npm`, and `apt` respect the gate. All web requests, including `curl` and `requests`, go through Time Portal.\n- **What makes a good portal**, in their framing: **coverage** (the agent can reach information that was on the live web at the as-of instant) and **leakage** (no privileged hindsight is exposed). The post says they spent the past 90 days working to those properties.\n- **Forecasting experiment** (vendor-reported): they deployed forecasting agents on 347 live prediction-market questions from Kalshi and Polymarket, then weeks later replayed the same questions through Time Portal with the as-of instant set to the original forecast time. Ablations used the live web or no web at all. The company says Time Portal replays showed no significant deviation from the historical live runs (**r = 0.98**). Agents replayed on the live web after resolution can look up the outcome and errors fall to nearly zero (**r = 0.16** in the post’s error-correlation chart). With no web, errors are larger and only loosely track the originals (**r = 0.49**).\n\nThe three endpoints live at `https://api.epochal.com/v1/time-portal/{search,fetch,sandbox}`. Every request takes an API key in `x-api-key` and the as-of instant in `Accept-Datetime`. A Python SDK wraps the suite (`from epochal.api import Client`, then `client.time_portal(\"2025-03-01T00:00:00Z\")`). There is also an interactive visualizer for browsing the historical web with a time-ported agent.\n"
