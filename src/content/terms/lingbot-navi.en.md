explain: "## What the company claims\n\nThe account below comes from the [product page](https://technology.robbyant.com/lingbot-navi), the [GitHub README](https://github.com/Robbyant/lingbot-navi) and the [launch post](https://x.com/robbyant_brain/status/2126020732610302086). It is the vendor’s description.\n\nRobbyant frames the problem as continuous robot navigation: using earlier observations to understand a new language request and reach a target that is no longer in view. The proposed link is **spatial memory**, which ties historical scene evidence, the current image and language together.\n\nThe product page says each 3D visual token pairs a surface location with a pretrained vision-language feature. A spatial-memory encoder, a vision-language decoder and a trajectory decoder then handle localisation, grounding and route prediction, and a local planner executes the route. The repository also describes reusable 3D memory—visual features anchored to reconstructed surfaces and packed into compact spatial tokens across local reconstruction blocks—and unified scene understanding plus navigation: object grounding, image localisation, spatial question answering and 3D route prediction.\n\nThe launch post says LingBot-Navi uses LingBot-Map 2.0’s reusable 3D spatial memory so a robot can find targets from natural language, plan a path and navigate to a nearby docking waypoint. The install notes call for Linux x86_64, Python 3.10+ and an NVIDIA GPU, with the CUDA 12.8 toolkit required for rendering.\n\n## Limits\n\nThis is a research-and-engineering preview. Star counts were still very low at release, and real-robot success depends on map quality, calibration and the deployment site. Spatial memory leans on LingBot-Map reconstructions, so drift or corrections in the map feed through to navigation. The demos and dataset focus on reconstructed workplace scenes; outdoor or very different layouts need a fresh evaluation. Read the repository licence, the model cards and Ant Group / Robbyant terms, and keep safety interlocks on a real robot. Do not confuse this with LingBot-Touch (touch sensing) or unrelated chat models that share a similar name.\n"
