explain: "The blog says the training tasks were built with Eigent AI, with about 1,200 selected from candidates in machine learning, software engineering, science, and other fields. Selection criteria included targeting mistakes the base model makes and tuning solve rates so tasks were neither too easy nor too hard; chaining interdependent problems into long jobs, with up to 1.5 hours in a sandbox, more than 100 tool calls, and more than 256K output tokens per attempt; and reviewing tasks so they could not be passed by reward hacking. Training ran in Miles’s fully asynchronous mode: 128 H200s ran agent inference and 16 ran the trainer. The release run is described as training for weeks on 144 H200s, 63,000 GPU-hours in total. The post also gives efficiency figures versus an open-source trainer, such as 37% model FLOPs utilization on this run versus 16% for the comparison trainer, and about 2× end-to-end throughput. Those are company claims. The sandbox service is built on open-source AgentENV; the authors say it ran about 944,000 sandboxes over nine weeks, with up to 1,566 running at once.\n\nOn results, the largest stated gain is Terminal-Bench 4.1 pass@1, from 5.6% for the base model to 12.0% (averaged over 8 runs per task, using RadixArk’s internal mini-swe-agent harness with summarization on). The model card adds that DaisyRose-27B keeps the base model’s architecture, tokenizer, chat template, image understanding, and 262,144-token context, and is intended as a drop-in replacement for Qwen3.8-27B. It has 27.8B parameters in total, including a 0.46B vision encoder and a 0.42B multi-token-prediction head, both left unchanged from the base model. SGLang documents a deployment recipe.
