intro: "**Claude Mem** (repo `thedotmack/claude-mem`, sites https://claude-mem.ai and https://cmem.ai , docs at https://docs.claude-mem.ai ) is persistent memory for coding agents. It captures tool activity, edits, and commands during a session, compresses them with AI into structured notes, and injects the relevant pieces into later sessions, machines, or tools. The homepage line is “All your context. Everywhere. All at once.” The local engine is open source and stores data on your machine by default (`~/.claude-mem/`, including a SQLite database).\n\nThe site and docs list hosts such as Claude Code, Cursor, Codex CLI, OpenCode, Gemini, Hermes, Copilot, OpenClaw, Windsurf, Antigravity CLI, and Grok Bot. What actually gets captured depends on the integration you install. Recall can be exposed to other MCP clients, including ChatGPT when the account supports custom connectors, but connecting ChatGPT does **not** automatically capture ChatGPT conversations.\n\nHighlights:\n\n- Install with `npx claude-mem install`, or in Claude Code run `/plugin marketplace add thedotmack/claude-mem` then `/plugin install claude-mem`. Do not rely on `npm install -g claude-mem` alone—that installs the SDK/library and does not register hooks or start the worker;\n- The local engine is free and open source. **CMEM Pro** is the paid hosted-observation and cloud-sync service; it is pre-selected in the installer, the docs mention a 30-day free trial, and after that you subscribe or fall back to your own provider (for example an Anthropic plan);\n- Progressive recall lets an agent find a note before reading its details; hosted observation moves memory generation off your primary agent’s subscription without changing that other plan’s price or limits;\n- TeamBrain is still a pilot and public team pricing has not been announced. Radar recorded about 115k GitHub stars on the weekly trending list in this window."
explain: "## Why it matters\n\nOne of the most expensive habits in agent coding is re-explaining, every new session, why a retry policy exists or why the project still uses SQLite. Claude Mem stores those decisions, discoveries, and fixes as searchable project notes instead of raw transcripts, so the next session, machine, or tool can look up a note before rereading the whole chat. If you bounce between Claude Code, Cursor, Codex, or more than one computer, a local store plus optional cloud sync is more flexible than memory locked inside a single chat product.\n\nIts place on GitHub’s weekly trending list in this window is a reminder that cross-session memory for agents is a real pain point. CMEM Pro moves compression and observation off your primary model quota and adds sync across machines, while the local engine still works on its own.\n\n## Limits\n\nCapture depends on the tool and integration you install; connecting a client does not mean every conversation in every product is recorded. On ChatGPT, the current role is mainly recalling notes that were already synced. Compression itself costs model calls: locally you can use your Anthropic, OpenRouter, or Gemini setup, while CMEM Pro uses hosted observation. The pages we checked do not publish a citeable monthly price, so this entry does not invent CMEM Pro pricing. Requirements include Node.js 20+, Bun and uv (the installer can set those up), and a new enough Claude Code host (docs say exec-form hook arguments need 2.1.139 or later). Data lives in `~/.claude-mem/`; if you enable cloud sync, synced data is also stored by CMEM, so read the privacy policy first. The star count is a scan-time observation and will change."
usage: "1. On your own machine run `npx claude-mem install`, pick the agents to hook up (or pass something like `--ide claude-code`), and choose a memory provider: your Anthropic plan, your own OpenRouter or Gemini key, or CMEM Pro;\n2. In Claude Code you can instead run `/plugin marketplace add thedotmack/claude-mem` and `/plugin install claude-mem`, then start a new session. Afterward, `npx claude-mem doctor` checks whether the hook launcher is on your PATH;\n3. Add CMEM Pro when you want hosted observation and cloud sync (docs mention a 30-day trial). Do not treat an unpublished monthly price as a fact. MCP clients such as ChatGPT are mainly for recall and do not automatically record those chats;\n4. Data defaults to `~/.claude-mem/`. Uninstall with `npx claude-mem uninstall` and update with `npx claude-mem update`. Read the privacy policy before turning on cloud sync."
