intro: "**AutoBots** 是 Vorflux 在 2.0 版本里推出的产品：把智能体雇成一个常设岗位（on-call、云成本、捉 bug、发版经理等），让它住在自己的 Slack 频道里全天候工作，而不是只做一次任务。Vorflux 创始人 Prasanna Sankar（Rippling 联合创始人）在 2026-11-10T17:22:15Z 的[宣布帖](https://x.com/myprasanna/status/2120205408371634624)中介绍了 AutoBots；官方账号 [@vorfluxai](https://x.com/vorfluxai/status/2120207179034906827) 同期写到 “Vorflux 2.0 is now live.” 产品文档在 [vorflux.com/docs/autobots](https://vorflux.com/docs/autobots)，目录在 [vorflux.com/bots](https://vorflux.com/bots)，站点为 [vorflux.com](https://vorflux.com/)。\n\n按宣布帖和文档，Vorflux 1.0 已经能让人从 Slack 或 Linear 把任务交给云端编码智能体并在那里审代码，但启动、跟进和找对人审批仍然要人来做。AutoBots 被设计成“新员工入职”的形态：接到数据源后主动找最高优先级的工作，随成果被接受而加大工作量，无人互动时再收束，并保持在预算内。文档写明产品在应用里统一叫 Autobots / AutoBots（侧边栏、雇用页和编辑页），少量旧文案仍可能出现 Worker bot，含义相同。上线时有 14 个模板，各带人设、岗位定义、建议集成和默认预算（文档写每个模板起步为每天 100 美元、每周 1000 美元，可在设置对话或成本管理里改）。模板例子包括 On-call Assistant、Cloud Cost Assistant、Code Janitor、Bug Bot、Release Manager 等。\n\nSankar 在宣布帖中还称，团队可以带上已有的 Codex 或 Claude Code 订阅，并称 Vorflux 已完成 1500 万美元种子轮，投资方包括 Y Combinator、Peak XV Partners、Alliance DAO 以及多名个人投资者。这些融资和“几乎免费”的表述是创始人陈述，条款与价格以官网和合同为准。演示视频章节也包括 on-call、项目经理、客户体验、设计师和社交等 AutoBot。\n\n要点：\n\n- 官网：https://vorflux.com/ ；文档：https://vorflux.com/docs/autobots ；目录：https://vorflux.com/bots ；\n- 创始人宣布帖（2026-11-10T17:22:15Z）：https://x.com/myprasanna/status/2120205408371634624 ；\n- 官方账号帖：https://x.com/vorfluxai/status/2120207179034906827 ；\n- 这是 **Vorflux 2.0 里的新产品名**，不要和变形金刚里的 Autobots，或“Vorflux 2.0”这个版本号本身混为一谈。"
