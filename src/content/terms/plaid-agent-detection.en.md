intro: "**Plaid Agent Detection** is the new Plaid product formally introduced on 16 November 2026 for telling whether an interaction is coming from a person or an AI agent, and which agent it is. [@Plaid](https://x.com/Plaid/status/2122363341200937381) posted the introduction at 2026-11-16T16:17:06Z (00:17:06 Beijing time on 17 November 2026). How it works and where we’re headed:”, and points to the official blog.\n\nThe official post at [plaid.com/blog/agent-detection-agentic-finance](https://plaid.com/blog/agent-detection-agentic-finance/) is dated November 16, 2026, titled “Introducing Agent Detection: building trust in the age of agentic finance,” and attributed to Pedro Sanzovo, Head of Fraud. It says: “Today we're introducing Agent Detection, giving fintechs, banks, and other financial companies visibility into whether an interaction is human or agent-driven, including which agent.” Plaid argues that traditional device and behavior checks struggle when AI agents can navigate websites much like people do. Agent Detection, it says, looks at thousands of signals across devices, behavior, automation patterns, and network activity to identify whether an interaction is coming from a human or an AI agent, and which AI provider the agent is associated with. The example in the post is a consumer asking an AI agent to pay an upcoming bill: the financial institution can recognize that an agent is behind the interaction and use that information to shape how it supports agent-initiated payments.\n\nPlaid also says Agent Detection is fine-tuned for financial interactions of this kind — it already runs device, behavior, and network intelligence across hundreds of institutions for financial logins, and can therefore tell the difference between an agent logging in as a bank customer and an agent shopping. In side-by-side testing on live traffic, Plaid says Agent Detection identified 2.3× more agent sessions than competitors with no increase in false positives. Businesses can use it across digital experiences from login and sign-up to money movement through a lightweight SDK that does not interrupt the existing user experience; for customers already using Plaid, it may also be available through their existing integration, with minimal additional setup. The company describes Agent Detection as the first step toward trusted agent interactions, and says it is expanding the existing Trust Index and building on consumer-permissioned access infrastructure for companies that want a dedicated path for AI agents. Those follow-on capabilities are still described as under construction — do not write them as already shipped.\n\nKey points:\n\n- Official introduction: https://x.com/Plaid/status/2122363341200937381 ; official blog: https://plaid.com/blog/agent-detection-agentic-finance/ ;\n- This is **a concrete new Plaid product name**, not the existing Trust Index, and not Plaid’s older account-linking or payments-risk features. The 2.3× detection figure is a company statement from a comparison test; this page does not independently reproduce it."
