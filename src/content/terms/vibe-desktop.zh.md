intro: "**Vibe Desktop** 是 [Mistral AI](https://mistral.ai/products/vibe/) 在 2026 年 11 月 17 日推出的官方桌面应用，把已有产品 **Mistral Vibe**（由 Le Chat 更名而来，包含 Vibe Work 与 Vibe Code）放到同一个 macOS / Windows 客户端里。官方账号 [@MistralAI](https://x.com/MistralAI/status/2122713547952324750) 于 2026-11-17T15:28:42Z（北京时间 11 月 17 日 23:28:42）在一条产品线帖里写：“Oh, and Vibe desktop is here! Hand Vibe several tasks at once, watch the agents work side by side, then review their diffs and track pull requests in the same window.”本轮扫描核对该帖时约 101 次点赞、约 8,002 次展示。同一条线的起始帖还在推欧洲地区 Vibe 短期免费码，互动更高，但桌面客户端的直接宣布是上述这条。\n\n官方[发布说明](https://docs.mistral.ai/resources/release-notes)把当天更新题为 “Vibe Desktop: Work and Code in one app”，并标为 New Release、General Availability、Mistral-Hosted。说明写到：可在本机仓库或托管的云沙箱里跑编码任务，在同一窗口里组织多段对话、查看文件、命令和 pull request；本地会话共用 Vibe CLI 的核心代理引擎和会话日志，但并不内嵌或运行 CLI 应用，也不需要单独安装 CLI，工具与提示词可以不同。Linux 支持即将到来。\n\n产品页 [mistral.ai/products/vibe/](https://mistral.ai/products/vibe/) 与 [vibe/code](https://mistral.ai/products/vibe/code/) 提供 macOS 与 Windows 的下载入口（例如 [macOS](https://chat.mistral.ai/download/vibe-desktop/mac?from=website) 与 [Windows](https://chat.mistral.ai/download/vibe-desktop/windows?from=website)）。不要把 Vibe Desktop 写成一条全新的模型，或写成第三方社区套壳（此前已有非官方桌面客户端的功能请求）；它是官方对已有 Vibe 产品线新增的桌面端。"
explain: "在官方文档 [Choose CLI, VS Code, web, or Desktop sessions](https://docs.mistral.ai/vibe/code/choose-cli-vscode-web-sessions) 里，Vibe Code 有四种正式界面：CLI、VS Code 扩展、Vibe Code Web，以及 Vibe Desktop。它们共用核心代理引擎，但运行时、工具和提示词可以不同。Vibe Desktop 的定位是“把云会话和本地会话放进同一个桌面应用”：本地会话对着本机克隆的仓库和开发环境工作，云会话则走托管沙箱，并可直接连 GitHub 仓库。\n\n11 月 17 日发布说明列出的能力包括：在集成终端里执行命令，用 Git worktree 隔离并行改动；把本地文件夹加进 Vibe Work；协调子会话并查看被委派的子代理对话；让构建、开发服务器和文件监视在后台运行，并在面板里查看输出或停止进程；在应用内浏览仓库文件、查看 Unified / Split diff，以及检查 pull request 的标题、编号和状态；内置浏览器用来并排打开文档、issue、仪表盘和 PR；用项目、固定/归档对话、命令面板和快捷键切换任务；以及系统原生通知。这些都是官方功能说明，不是第三方评测。\n\nVibe 本身并不是这一天才出现的产品：官方产品页写明 Vibe 是 Mistral 的工作与代码助手，Le Chat 已更名为 Vibe，对话、设置和方案会沿用。因此本词条记录的是 11 月 17 日正式发布的 **Vibe Desktop** 客户端，而不是把整个 Vibe 当成新词。起始线帖还提到 Vibe 与 Le Chonk（即已收录的 Mistral Large 4）在编程与安全任务上的组合，以及欧洲地区限时免费码；那是同期促销，不是桌面端本身的规格。"
usage: "按[发布说明](https://docs.mistral.ai/resources/release-notes)的起步步骤：下载 Vibe Desktop，用 Mistral 账号登录，然后在 Work 或 Code 里开一个具体任务。官方下载入口在产品页 [mistral.ai/products/vibe/code/](https://mistral.ai/products/vibe/code/)，目前提供 [macOS](https://chat.mistral.ai/download/vibe-desktop/mac?from=website) 与 [Windows](https://chat.mistral.ai/download/vibe-desktop/windows?from=website)；Linux 尚未作为正式平台写出。登录后即可在同一窗口里同时使用 Vibe Work 与 Vibe Code。\n\n若已有 CLI 或 VS Code 扩展上的会话：文档写到，CLI 与 VS Code 扩展共享配置和会话，可以来回接着用；Desktop 的本地会话共用 CLI 的核心引擎和会话日志，但工具与提示词可能不同，也不需要再单独安装 CLI。需要纯终端、脚本或 CI 时，仍应使用 CLI（例如 `vibe --prompt`），因为发布说明写明 Desktop 没有非交互模式。在其他 IDE 里，Vibe 还实现了 Agent Client Protocol（ACP），可在 JetBrains 等兼容客户端中运行，设置见官方文档 “Use Vibe in other IDEs”。企业侧的私有化部署与微调（Mistral Forge）属于整个 Vibe 产品，而不是 Desktop 专属能力。"
