intro: "**Xiaomi-OCR-0** is an open-source, **0.8-billion-parameter** OCR-specialised vision-language model from **Xiaomi** (released under the `xiaomi-research` organisation on Hugging Face). A single compact model handles three jobs that normally need separate tools: **whole-page document parsing** (text, tables and formulas to Markdown/LaTeX/OTSL), **key information extraction (KIE)** into JSON, and **OCR-centric visual question answering**.\n\nWeights and a technical report (arXiv:2609.36136) were published at the end of September 2026; on **October 30, 2026** Xiaomi's official account announced it on X, the post passed 2,500 likes, and the model became one of the most discussed small OCR models of the week. It is licensed **Apache-2.0**, so commercial use is allowed."
explain: "## Key facts\n\n- **Size**: ~0.8B parameters (about 1.8 GB in BF16), fine-tuned from **Qwen3.5-0.8B-Base**.\n- **Training data**: roughly **170M** OCR-centric samples built by a data engine that uses *Ensemble Triplet Consensus* across expert OCR models, render-guided verification and targeted synthesis.\n- **Training recipe**: Q-Mask text anchoring → OCR-centric continued pre-training → **Mix-RL** (mixed-task reinforcement learning with verifiable rewards).\n\n## Benchmarks (as reported by Xiaomi)\n\n| Benchmark | Score |\n| --- | --- |\n| Real5-OmniDocBench | **95.24** (#1) |\n| OmniDocBench v1.6 | 96.83 (#2, best under 1B) |\n| Wild-OmniDocBench | 87.94 |\n| UniMER-Test (formulas) | 97.84 |\n| PubTabNet (tables) | 92.27 |\n| 5 OCR-VQA benchmarks (mean) | 83.2 – above Qwen3.5-2B |\n\nCommunity tests posted on X report it beating LFM3-VL-2B on receipts (23/23 lines vs 21/23). Note that the public Real5 leaderboard shows a slightly lower number than Xiaomi's own claim, so treat headline scores as vendor-reported.\n\n## Why it matters\n\nMost strong document parsers are 1B+ parameters or cloud APIs. Xiaomi-OCR-0 brings near state-of-the-art parsing and field extraction to laptops, consumer GPUs (it runs on an 8 GB RTX 2070) and even edge devices, which is ideal for invoice/receipt pipelines and private on-device document AI."
usage: "## How to try it\n\n1. **Hugging Face**: download `xiaomi-research/Xiaomi-OCR-0` and run it with Transformers (`AutoModelForImageTextToText` + `AutoProcessor`). Xiaomi's verified combo is `transformers==5.17.0`, `torch==2.14.0`.\n2. **Ollama (experimental)**: `ollama pull longwayxu/xiaomi-ocr-0:bf16`, then use the repo's **MCP service** or browser demo so the correct preprocessing and prompts are applied.\n3. **llama.cpp / GGUF**: community quantisations such as `prithivMLmods/Xiaomi-OCR-0-GGUF` (remember the `mmproj` vision projector).\n\n## Task prompts\n\n- Whole page: *\"Extract all information from the main body of the document image and represent it in markdown format…\"*\n- Text region: *\"Extract the text in the image.\"*\n- Table: *\"Parse the table in the image into OTSL.\"*\n- Formula: *\"Identify the formula in the image and represent it using LATEX format.\"*\n- KIE: *\"Extract key information in the image\"* + your JSON schema.\n\n## Good fits\n\n- Receipt / invoice / form extraction straight to JSON\n- Converting scanned PDFs and photographed pages to Markdown for RAG\n- An OCR tool for coding agents via the bundled MCP server and Agent Skill"
