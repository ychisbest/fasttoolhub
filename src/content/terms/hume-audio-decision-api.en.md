intro: "**Hume Audio Decision API** (the docs also call it the Audio Decisions API) is an **audio-native decision model** launched by emotion-aware voice AI company **Hume AI** on **November 2, 2026**. Developers send raw audio plus plain-language questions (\"Does the caller sound frustrated?\", \"Is this voice AI-generated?\", \"Is there a siren in the background?\"), and the model returns **probabilities over the answers** instead of a transcript or a chat reply.\n\nHume calls it \"the first audio-native model that answers questions about speech and sound,\" aimed at the gap where voice agents only read transcripts and miss tone, pauses and sighs."
explain: "## How it works\n\n- **One request = one audio file + many questions**, all answered in a single inference.\n- **Four question primitives**:\n  - `noul`: yes/no, returning the share of human raters who would say yes;\n  - `choice`: pick among unordered options, with probabilities;\n  - `score`: position on an ordered scale, with score, confidence and distribution;\n  - `span` (experimental): time ranges where an event occurs, best for vocal bursts and sound events.\n- **Numbers only**: no transcript, explanation or reply. Your code thresholds, ranks or combines the outputs, which makes it easy to wire into business rules or agents.\n- An optional `context` string describing the recording can improve results.\n\n## Specs and pricing\n\n| Item | Detail |\n|---|---|\n| Endpoint | `POST https://api.cloud.hume.ai/v0/decisions/file` (multipart) |\n| Audio | MP3 or WAV, 5 seconds to 5 minutes, heard as 16 kHz mono |\n| SDKs | Python `hume-audio-decisions`, TypeScript `@humeai/audio-decisions` |\n| Pricing | $0.47 per 1M input tokens; answers are not billed; 1M-token trial credit per organization |\n\nReported results: trained on 10M+ human judgments, it agrees with human raters about 70.7% of the time, versus 56.5% agreement between individual listeners."
usage: "## Typical use cases\n\n- **Call-center QA**: flag frustrated customers, repeated requests for a human, or agents talking over callers across large call archives.\n- **Voice-agent evaluation and live monitoring**: query clips every few seconds and trigger escalation or strategy changes.\n- **Trust and safety**: detect AI-generated voices or unusual background sounds.\n- **Audio archive search**: tag tens of thousands of recordings by tone and events so they become searchable.\n\n## Getting started\n\n1. Request access on the Hume Platform and get an API key (1M-token trial credit).\n2. Read the Audio Decisions docs at dev.hume.ai and estimate cost with the `input_tokens` endpoint.\n3. Send one MP3/WAV with a few `noul`/`score` questions via cURL or the SDK and inspect the probabilities.\n4. Set thresholds for your use case and route results into tickets, alerts or agent decision logic."
