Its pitch: \"Turn any MLLM into an evidence-based visual reasoner that thinks and codes in visual space.\"\n\nThe paper, \"OpenVLHarness: Real World Visual Agentic Tool-Use with Multimodal Memory\", was submitted to arXiv on October 19, 2026 (2610.26860). explain: "## How it works\n\nThe model chooses tools, inspects their evidence and continues until it can answer. Three components:\n\n- **Capability layer**: nine task-level interfaces turn tool outputs into readable observations (annotated images, summaries, compact numerical data)\n- **Multimodal memory**: images, boxes, masks, depth maps and web references stay addressable for the whole question; each new question starts with fresh memory\n- **Python Coding Agent**: the backbone writes code in a separate context to compute over stored boxes, masks, depth maps and other results\n\n## Nine capabilities\n\n| Capability | Default backend |\n|---|---|\n| Visual grounding | SAM 3 |\n| OCR | PaddleOCR-VL |\n| Depth estimation / camera trajectory | Depth Anything 3 |\n| Zoom-in | built-in image processing |\n| Text search / image search / webpage visit | Serper + Qwen |\n| Python coding agent | backbone + local Python |\n\n## Results (average over 22 benchmarks)\n\n| Backbone | Base | + OpenVLHarness |\n|---|---|---|\n| Qwen3-VL-8B-Instruct | 34.24 | **45.41** |\n| Qwen3-VL-32B-Instruct | 38.30 | **50.92** |\n| Kimi K3 | 56.43 | **66.09** |\n| GPT-6 Astra | 60.27 | **70.17** |\n\nThe paper reports that with GPT-6 Luna at medium effort it beats the base model, Codex and Visual Sketchpad at maximum effort by 7.7–8.5 points while using at most 37% of their model-token cost."
