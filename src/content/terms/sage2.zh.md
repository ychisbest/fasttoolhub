intro: "**Sage2** 是 **Levanto Labs** 于 **2026 年 11 月 2 日** 正式发布的 **运行时决策与抽取模型**。开发者把自然语言文本（聊天、工单、文档片段）和问题/字段定义发给 API，模型返回 **带校准概率的是/否或多选决策**，以及 **带证据片段的结构化抽取结果**；支持 WebSocket **流式会话**：上下文边到达边更新答案，官方称流式决策可比整段重算快约 3 倍，短文档抽取约 **150 ms**，流式决策最低约 **50 ms**。\n\n它与库中的 **Sage-A1.5**（InternScience 科研模型）不是同一产品线；Sage2 面向应用运行时的“决策/抽取原语”，可直接接到客服、销售、交易与游戏等持续对话场景。官网提供产品页、文档、Playground，并宣称新用户可获约 **2000 万免费 token**。"
explain: "## 核心能力\n\n- **Decide**：用自然语言定义是/否或多选问题（如“是否要求退款？”“要不要升级到 on-call？”），返回答案与概率，适合路由工具、工单分级。\n- **Extract**：定义字段（金额、日期、时长、文本等），从自然语言中抽出类型化取值，并带回源文本片段与概率。\n- **Stream**：打开流式会话后只追加新文本，服务端复用前缀计算；可每次都发射更新，或只在答案变化时推送。\n- **多模态**：官方称 Sage 也可分析图像。\n- **Extract Bench**：Levanto 自建抽取评测，自称准确率 77.8、识别“无答案” 72.2，高于 Cloudflare Clairic（75.3 / 59）；基准开源在 GitHub。\n\n## 接入与生态\n\n- 文档与 API 合同可直接交给编码智能体集成；现有 Sage key 可继续用于抽取与流式。\n- 也可经 **NEAR AI** 机密推理、以及面向智能体的 **MPP**（配合 Stripe / Tempo）调用。\n- 案例侧提到 Leap（识别学习工具请求）、Capacitr（市场分析决策点）、PerpFlow（把重复分类委托给 Sage）等。\n\n以上延迟、成本倍数与榜单数字均为厂商自述，独立复现仍有限。"
