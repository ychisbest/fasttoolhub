explain: "## Design: structure first, pixels on demand\n\nMost browser-automation tasks need page structure, not a continuously rendered picture. Moli treats the native DOM and style state as the single source of truth:\n\n- **Extract HTML/Markdown, query the DOM, run JS, inspect network/storage**: reads runtime state directly, with no layout or paint\n- **Read an element's box, hit-test coordinates, send coordinate input**: runs one layout pass and keeps only the latest frozen layout tree\n- **Screenshot**: rebuilds from the current DOM/style, renders a fresh frame, then discards paint state\n- **Screencast**: emits no frame while state is clean; rebuilds only when something changed\n\n## Capabilities\n\n- **Complete web runtime**: streaming HTML parsing, native DOM, V8 JavaScript, iframes and workers, CSS cascade, Fetch/XHR/WebSocket, cookies, WebCrypto, and storage (localStorage, IndexedDB, OPFS)\n- **Extraction-optimized outputs**: the CLI produces HTML, Markdown, JSON and semantic text trees\n- **One automation binary**: the same endpoint speaks **CDP, WebDriver Classic and WebDriver BiDi** — no separate ChromeDriver, geckodriver or browser install\n- **Visual features on demand**: `--layout` enables full layout, hit-testing and screenshots; `--resource` also fetches images, fonts, audio/video\n- Runs on Linux, macOS and Windows\n\n## Where it fits\n\nLexmount says this cost model suits crawling, browser-use agents, retrieval pipelines, evaluation environments and reinforcement-learning workloads."
usage: "## Run it locally\n\n```bash\n# DOM-first automation server\nmoli serve\n# enable real geometry, coordinate input and screenshots\nmoli serve --layout\n# also fetch optional images, fonts, audio/video\nmoli serve --layout --resource\n```\n\nPlaywright connects directly over CDP:\n\n```js\nimport { chromium } from \"playwright\";\nconst browser = await chromium.connectOverCDP(\"http://127.0.0.1:9222\");\n```\n\n## Use it in the cloud (Lexmount Cloud Browser)\n\nIn the Lexmount SDK, Moli is the browser mode with API value `light`:\n\n```python\nfrom lexmount import Lexmount\nwith Lexmount() as client:\n    with client.sessions.create(browser_mode=\"light\") as session:\n        print(session.id)\n```\n\nNote: hosted Moli does not support contexts, extensions, persistent replay or stored downloads. Use Chromium (`normal`) mode when you need those, and validate your target pages first.\n\n> Details: GitHub `lexmount/moli` and browser.lexmount.com."
