intro: "**MAI Code 2** 和 **MAI Code 2 Flash** 是 [Microsoft AI](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/) 在 2026 年 11 月 17 日（文章归类为 Ignite · Models）正式介绍的一对编程模型，定位是日常企业编程任务上的性价比，而不是科学研究或超长程 agent 工作。官方写到，Code 2 擅长把代码推到可合并的生产改动、深层调试、多文件实现、仓库级推理和界面；Flash 则面向解释代码、局部修改、常规修复和快速迭代这类高并发工作。\n\n同一 Ignite 模型套件里，雷达已在 04:32 一轮收录 **MAI Image 2.7 / MAI Image 2.7 Flash**。Code 2 与 Code 2 Flash 是该套件中此前未入库的编程型号，官方新闻页在本轮窗口内更新到 microsoft.ai 站点地图。微软还提到，会从 Code 2 Flash 再优化出一个主要用于 Microsoft 365 和 Fabric IQ 的 **MAI Work Flash**；它是产品内专用变体，本轮只在本词条中说明，不单独建页。\n\n入口方面，官方写明两款模型已在 GitHub Copilot 提供，Code 2 Flash 还在 Microsoft Foundry 做限量预览，并预告将登陆 OpenRouter、Vercel、Hermes、Open Code 和 Kilo。定制则指向 Microsoft AI 的 Custom Models / Licensed Weights 说明页。"
explain: "官方评测需要按原文和脚注来看。微软称，在面向 GitHub Copilot 日常企业编程任务的四项基准（DeepSWE 1.1、Terminal Bench 2.1、SWE-Atlas 和 FrontierCode v1.1）上取平均，MAI Code 2 达到 GPT-6.1 Sol 约 98% 的表现、成本约为其 40%，以及 Claude Opus 5.5 约 96% 的表现、成本约为其 5%。前端盲测中，评审在界面、游戏、数据可视化、3D 场景和 SVG 等方面有 64% 的次数更偏好 Code 2，而不是 GPT-6 Sol，标注共 258 人。Flash 则称在三项日常高并发编程基准上，表现可与 GPT-6 Luna、Claude Haiku 5.5 相比，成本分别约为其 65% 和 20%。脚注写明部分成本按 50% 促销价展示，且结果随任务、推理强度和计价假设变化。\n\n在“Beyond coding”一节，微软还给出了由 Code 2 Flash 进一步优化的内部模型在 Excel、PowerPoint、Word、Teams 和 Fabric IQ（含 Power BI 语义模型上的 DAX 生成）等产品场景中的对照，并把它称为 MAI Work Flash。这些是产品内评估，不意味着 Work Flash 已作为独立公开模型对外发售。官方也明确：这两款模型“explicitly not yet tuned for harder problems, like fundamental science research and very long horizon agentic work”。"
